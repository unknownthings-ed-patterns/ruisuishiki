# VISION — 推理式で貫く、小1から大学数学まで

**この文書の位置づけ**：これは**ビジョンであり構想**であって、実装のルールではない。ルールは `CLAUDE.md`（お手本7条件・チェックリスト）と理論文書4弾（vault `個人/`）が正であり、齟齬があればそちらが勝つ。この文書が担うのは「**どこまで行くつもりなのか**」という射程の宣言と、そこへ向かうときに立つ**未解決の設計問題**の一覧である。

初版：2026-07-29（岩井の構想を言語化）。更新は岩井の裁定でのみ行う。

---

## 1. 到達像

**小学1年から大学数学（線形代数など）まで、推理式エンジンで作られた問題群が一本につながっている学習プラットフォーム。**

やる気のある小学生・中学生が、公文式のように自分の速さで自学自習を続けながら、途中で壁に当たらずに大学数学まで歩き通せる。教材の形は「参考書兼問題集」に近い——青チャートのような一冊が、全ページ推理式の配列で貫かれているイメージ。

現在は高校数学（数Ⅰ・Ⅱ）を中心に、岩井自身の学び直しの軌跡に沿って作られている（[development-loop]）。上（大学数学）と下（小学校算数）は、まだほとんど空いている。

## 2. なぜ「公文式のように」で終わらないのか

公文式の強みは疑いない——毎日回る量、自学自習、スモールステップ、進度の可視化。ruisuishiki が学ぶべきものが多くある。

だが公文式が高校数学の手前で失速するのは、生徒の意志や量の問題ではなく**方式の構造**による。あの設計は実質、推理式でいう **Op1（同）＝同じ文型で材料を置換する反復**だけでできている。刻みをいくら細かくしても、同オペレータの連鎖は次の段差を越えられない：

- 数から式へ（具体の量 → 文字が量を代理する）
- 静から動へ（決まった値 → 変化する量、関数）
- 量から構造へ（計算できる → 何が保存されるかを問う、線形性・群）

これらはすべて **Op4（質的変化）** が要る。推理式は最初から5オペレータを配列の必須条件にしている（[core-principles]）ので、**公文式の「毎日回せる自学自習」を保ったまま、公文式が構造的に越えられなかった段差を越える**——これが本プロジェクトの射程の核心である。

そして越え方が「解説を足す」ではなく「**比較を指さす**」であることも譲らない。加法定理の系列で既知の定理から tan を導かせるヒントは、反復ドリルからも解説動画からも原理的に出てこない。ここが最も模倣されにくい独自性の源泉である（第2弾§10）。

## 3. 貫く縦の鎖（胚細胞は学年をまたぐ）

「小1から大学まで」は、単に系列を大量に並べることではない。**同じ胚細胞が、学年をまたいで何度も別の顔で現れる**という構造を設計することである。すでにユニット内では実現している（三角比のハブ胚細胞が数Ⅱ一般角の下側に接続している、等）。それを学年間に延長する。

想定される鎖の例（確定ではなく、単元設計時に検証されるべき仮説）：

| 鎖 | 小学校 | 中学校 | 高校 | 大学 |
|---|---|---|---|---|
| **比と形** | 形をくらべる・拡大縮小 | 相似・比の値 | 三角比 → 単位円 → 三角関数 → 加法定理 | 回転行列 → 線形変換 |
| **線形性** | 同数累加としてのかけ算 | 比例・一次関数 | 傾き・ベクトル | 線形写像・行列 |
| **変化** | 差をとる | 変化の割合 | 平均変化率 → 微分 | 微分作用素・線形近似 |
| **帰着** | くり下がり（扱える形に直す） | 移項・因数分解 | 平方完成・置換 | 基底の取り替え・対角化 |

この表の使い方：**新しい単元の背骨を設計するとき、その単元が上下どの鎖のどこに刺さるかを1行書く**。刺さらないなら、それは孤立した技能集になっている疑いがある。

（学年配当・章順のベース基準は従来どおり池田洋介『入門問題精講』の目次順を守る。この表は配当を変えるものではなく、**すでにある配当の下を通る糸**を見えるようにするもの。）

## 4. 射程の境界（正直に引いておく）

第2弾§10の修正版テーゼは、適用範囲を「**文型がよく抽出できる領域**（典型応用問題・計算技能）」に限定している。この制約はビジョンを大きくしても外さない。

大学数学に伸ばしたとき、実際にはこう分かれる：

- **推理式が貫ける**：線形代数の計算技能と典型問題（行列演算・連立方程式の掃き出し・行列式・固有値固有ベクトル・基底変換）、微積分の計算技能、確率統計の典型問題。**文型が立ち、解が一意で、機械が検証できる**
- **推理式だけでは足りない**：ε-δ論法、証明の構成、抽象代数の定義の運用、未解決性のある探究。これらは ill-structured 側であり、**エンジン外装置**（シンキング・タスク、作問、読み合い）が担う（F6）

したがって到達像の正確な言い方は「大学数学のすべてを推理式で置き換える」ではなく、「**技能と典型を推理式の縦糸が貫き、証明と探究はエンジン外装置の横糸が受ける**」である。これは「参考書兼問題集」という先生のイメージとむしろ整合的で、青チャートも計算技能と典型問題の書であり、証明の書ではない。

## 5. 未解決の設計問題（ビジョンと現実の間にあるもの）

ここが本文書の実務的な中身。**5年で到達したいなら、これらのどれかは必ず解かねばならない。**

### V-1 検収のボトルネック＝先生の学習速度

当初の開発サイクル（[development-loop]）は「岩井が紙で学ぶ → 系列を作る → 岩井が歩いて磨く」。品質はこれで守られている一方、そのままでは**コンテンツの上限速度が岩井一人の学習速度に固定される**。生成側（Fable/Opus）は1日で1ユニット8〜9系列を作れるので、律速は明確に検収側にある。

**二つのモードを状況に応じて使い分ける**（2026-07-29 岩井裁定）：

| モード | 手順 | 使いどころ |
|---|---|---|
| **同期**（当初の形） | 学ぶ → 作る → すぐ歩く | 新しい胚細胞が立つ単元・原則がまだ動いている領域 |
| **先行生成 → 後追いウォーク** | 素材を渡して背骨〜全系列を一気に作る → 岩井が後からゆっくり歩く | 骨格が確立した単元・同型展開が効く領域 |

先行生成は実績がある——**三角関数ユニット（全9系列）**は Fable が一気に実装し、岩井が後から歩いた。指数対数・三角比も同型。したがって V-1 は「解かねばならない未知の問題」ではなく、**すでに片方の解が動いている**。残る課題は使い分けの判断基準を精緻にすることと、下の緩和策を必要に応じて足すこと。

さらに考えうる緩和（未裁定）：
- 検収を二段にする——**新しい胚細胞が立つ系列だけ岩井が歩き**、同型展開は機械検査＋Opus 検収で通す
- 歩く人を増やす——小学校系列が整えば、担任している子どもたちが二人目以降のテストユーザーになりうる（[task-low-floor] が効く）
- 「歩いていない系列」を正直にラベルする——質の担保を偽らない

**ただし品質基準を下げる形での緩和は採らない**。お手本7条件＋Q1〜Q7 は5年後も基準である。先行生成でも、機械にかかる検査（audit_hints・5オペレータ網羅・tsc/test/build・数値検算）は**歩く前に全部通す**。人が歩いて初めて分かること（言葉の選び・図の見え方・問いの順序）だけを後追いに回す。

### V-2 小学校低学年の入力系（C1ゲート）

現行の系列フォーマット（10ステップ・数値入力・ヒント3層）は小1にそのまま使えない。原則7「匡救の設計」とローフロア（[task-low-floor]）が要求するのは、**具体操作・身体活動で全員が入れる入口**である。背骨設計の条件 C1（入力系ゲートを最初に）に従えば、小学校ユニットに着手する前に入力系の拡張——選択・並べ替え・絵の操作・数え上げ・音声——を先に通す必要がある。国語版の俳句で moraCount を先に通したのと同じ手順。

### V-3 継続の装置（公文式から学ぶべき唯一のもの）

公文式が持っていて ruisuishiki にまだ無いのは、**毎日回る仕組み**である。ただし進度の可視化は F8（履歴が正答率に堕ちる）と正面衝突する。したがって「文型×オペレータ軸のまま、続けたくなる」形を発明する必要がある。着手済みの M-4（そろそろ再訪＝間隔学習×検索練習）・M-6（混合復習）・T-5（オペレータの地図）はすべてこの問題の一部であり、ビジョンの視点からは**優先度が上がる**。

### V-4 大学数学のベース基準（誰の目次に乗るか）

章構成のベース基準は池田洋介『入門問題精講』（[chapter-order-base]）だが、**これは高校で尽きる**。大学数学に伸ばすときの目次の正をどこに置くかは未決。候補は標準的な線形代数・微積分の教科書だが、高校までと違い「学習指導要領＝公的カリキュラム」という著作権上安全な背骨が存在しない点に注意が要る。**構成は借りる・特定の問題値はオリジナルに**（[copyright-credit-vs-copy]）の原則はそのまま効く。

### V-5 ローカルファースト設計の耐用限界

学習履歴は localStorage（ブラウザ内）で、無料・静的配信・プライバシー最小収集というビジョン声明を支えている。だが「小1から大学まで10年歩く学習者」を想定すると、**端末が変わる・OSが消す・進度が消える**という現実に当たる。エクスポート/インポート、あるいは任意のアカウント連携をいつ入れるかは、無料と静的配信の原則を壊さない形で設計する必要がある。

## 6. 時間軸

岩井自身が数学Ⅱ・Bを独学中であり、開発は**その歩みと連動している**（これは制約であると同時に、机上の設計では出ない違和感を拾い続けるための最大の資産でもある）。大学数学に手が届くのが何年後かは確定できないが、**5年という見積もりは非現実的ではない**——高校数学一通りの残りは、現在のペース（素材読み → 背骨設計 → 実装 → 歩いて磨く）で年単位ではなく月単位で進んでいる。

律速は §5-V1 のとおり生成側ではなく検収側にあるが、**先行生成 → 後追いウォーク**という第二のモードがすでに実績を持つ（三角関数ユニット全9系列）。したがって5年という射程を支えるのは、**骨格の確立した単元は先に作り、歩くのは後から追いつく**という運用と、V-2（小学校の入力系）・V-3（継続の装置）を早めに解いておくことである。

## 7. この文書を実装判断にどう効かせるか

1. **新規ユニットの背骨に「上下の鎖」を1行**——§3 の表のどこに刺さるかを書く。刺さらない単元は孤立した技能集になっていないか疑う
2. **小学校系列を「あとで」に置き続けない**——V-2（入力系）が未解決である限り、小学校は永久に後回しになる。着手するときは系列より先に入力系ゲートから
3. **継続の装置（M-4/M-6/T-5）はビジョン優先度が高い**——単発の系列追加より効きが長い
4. **「歩いていない系列」を歩いたものとして扱わない**——質の主張を実態より大きくしない。これは第1巻の副題（形式は判断を自動化せず、判断の場所を監査可能にする）とも同じ規律
