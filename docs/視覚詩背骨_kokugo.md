## 権利の整理（2026-08-20 調査・**先生の想定への訂正を含む**）

1. **新国誠一（1925–1977没）・寺山修司（1935–1983没）は著作権切れではない**。旧法の死後50年ならそれぞれ2027年末・2033年末に切れるはずだったが、**2018-12-30 時点で保護中だった著作物は70年延長の適用を受ける**——新国は**2047年末**、寺山は**2053年末**まで保護。日本人著者のPDラインは**1967年以前没**（G12拡張条項・自由詩背骨で確立済み）で不変。関根栄一（1994没）・内田麟太郎（存命）も保護中。**手元の実物はすべて保護中＝サイトへの本文掲載は不可**。
2. **視覚詩は「部分引用」が成立しにくい**（作品全体が一つの形。美術作品と同じ）。全体引用の適法性を争う道はあるが、無料公開サイトで攻める必要はない→**保護中の実物はサイトに載せず、書誌＋リンクの「本物に会う」方式**（ファージョンの引用ベースよりさらに安全側）。**教室では35条でこれまでどおり見せられる**（先生の授業は不変・サイトとは別問題）。
3. **型・仕掛け（文字を並べて絵にする・数え上げ・一字だけ変える・最後の一行で種明かし）はアイデア＝自由**。構造だけ写して自作する（いつもの規律）。着想元は出典クレジット。
4. **使える現物の三本柱**：
   - **自作**（主力）——プレーンテキストの文字グリッドで組める視覚詩は自作で十分作れる。Fable 執筆＋先生裁定
   - **岩井輝久「白鳥のお散歩」**（licensed・本人許諾）——しかも構造が「はるのいけ」の**本歌取の実演**（Q→２・数え上げ継承・「すいすい」）。Step7 の本歌にそのまま立つ
   - **日本PD（1967年以前没）**——最有力＝**山村暮鳥「風景（純銀もざいく）」**（1915・1924没。「いちめんのなのはな」の反復＝視覚に働く詩の古典で、**暮鳥は系列①のPDプールに既にいる**＝縦の鎖）。上級参照＝萩原恭次郎『死刑宣告』（1925・1938没）。海外＝アポリネール『カリグラム』（1918没・日米ともPD）・ルイス・キャロル「ネズミのしっぽ」（1865）
5. sourceNote には没年・判定根拠を明記（従来書式）。「本物に会う」の内田・新国・寺山は書誌のみ（本文・図版とも非掲載）。

## 素材読解——目で見て楽しむ詩の仕掛け（全点から抽出）

1. **文字がものに化ける**：へ＝波（なみ）・Q＝おたまじゃくし（はるのいけ・ねえねえ）・8＝ゆきだるま（冬の校庭）・＋＝おはか（戦争）・△▽＝ワニの歯・、＝稲（たんぼ）・２＝白鳥（岩井）。新国は漢字で同じことをやる（〃の雨粒と「雨」・―と「引」・「土」のグラデーションと「大地」）
2. **くりかえしが量になる**（いちめんに並べると、けしきになる）
3. **一点の差異が物語を作る**：ワニの歯の▲一つ＝虫歯。冬の校庭の8の整列。「戦争」は差異ゼロの均質＝墓標
4. **数え上げが時間を作る**：はるのいけ（一ぴき→五十四ひき）・白鳥のお散歩（一匹→十七匹）
5. **さいごの一行（地の文）が絵をことばに裏返す**：「うみがわらっている」「——あーんして／——虫歯だね」「——ねずみさん こっちむいて」「——せいれつ ゆきだるまの朝礼だ」。**絵だけでは終わらず、短いことばが来て初めて詩になる**——俳句③「切れ」（二物の並置・言わない意味）の視覚版

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：共通胚細胞「小さな装置（型・語・配置）が大きな意味の体系を呼び出す」の**視覚詩の相**＝

> **文字は、読むだけのものではない。文字のすがたとならべ方が絵になり、さいごの短いことばと出会って、詩になる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> よまなくても、見ただけで、つたわってくるのは、なぜ？——文字のすがたと、ならべ方と、さいごの一行に、なにをさせられる？

## 5オペレータの視覚詩運用

| Op | 実装 |
|---|---|
| 同 | 同じ仕掛け（文字がものに化ける・くりかえし）で文字と題材を替える。本歌取＝「白鳥のお散歩」の型（数え上げ）を借りる |
| 逆 | 視覚詩→ことばの一文に戻す（「この詩をことばだけで言うと？」・戻すと何が消える？＝詩①・日記②と同型の逆） |
| ＋α | 制約追加：**一字だけ変えて意味を作る**（ワニの▲の手つき）・使う文字は一種類だけ・さいごの一行しばり |
| 質的変化 | **さいごの一行の発見**＝同じ文字の絵に、一行がある版／ない版——短いことばが来て、絵が詩になる（系列の核） |
| 複合 | 文字えらび＋ならべ方＋一点の差異＋さいごの一行、の重ね技で制作 |

## 技術ゲート（縦書き入力・実装前に通す）

1. **縦書き入力**：`textarea` に `writing-mode: vertical-rl` はモダンブラウザで動く。`KokugoInput` の poemText に**加法**で `orientation?: "vertical"`（既定は現行どおり）を足し、視覚詩 step では縦書き・全角等幅で入力→ PoemLines 表示と同じ見た目で作れるようにする。全角スペースで空白配置（placeholder で「ますをあけたいところは、ぜんかくスペース」を案内）。
2. **表示**：PoemLines は pre-wrap で空白保持済み。視覚詩は**字間を詰めた等幅グリッド**が命なので、視覚詩用に `letterSpacing: 0`・行間詰めの表示フラグ（MentorText に加法 `form: "visual"` など）を検討。清書カード流用。
3. **判定**：制作は判定しない（従来どおり）。choice/comparison のみ機械判定。
4. グリッド自由配置エディタ（新国「雨」級の2次元組版）は**初版では作らない**——文字と改行と全角スペースで組める範囲で始め、実walkで判断。
