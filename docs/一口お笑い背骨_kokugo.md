## 素材読解——一口お笑いの仕掛け

1. **型**：おなじ音で終わる行（脚韻）を重ねる＋**さいごの一行で裏切る（オチ）**。題は韻の音そのもの（「です」「さい」「とって」）。
2. **韻＝期待の装置**：おなじ音の連打がリズムと「つぎもこう来る」の期待を作る。**オチ＝裏切りの装置**：期待の上で、意味だけがひっくり返る。緊張と緩和——笑いの古典的構造を、音で組む遊び。
3. **これはファージョンの「破れ」の音版**：お話①（繰り返し3回→4回目の破れ）・視覚詩②（さいごの一行）・なぞなぞ詩③（さいごの比喩の跳び）と同じ原理の第四変奏——**反復が期待を作り、さいごの一回がそれを破る**。今回はそこに「笑い」という名前がつく。
4. **オチには2つの家族**がある：
   - **韻を守ったまま裏切る**（上級・気持ちいい）：「じゃあ　のこしなさい／ごめんなさい」「自分でしとって」「自分すぎって言いすぎ」（自己言及）「たいの気持ちはつらかたい」（視点が鯛へ）
   - **韻ごと投げ捨てる**：「やっぱりいらない」（買っての連打のあとで）
5. **声に出して完成する詩**：リズムと間。読み合い＝ライブ。
6. 韻あわせは**行末のかな比較**＝機械化と相性がよい（moraCount の親戚）。初版は choice で扱い、韻メーター（行末ハイライト）は将来の磨き候補。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：共通胚細胞「小さな装置が大きな意味の体系を呼び出す」の**音あそびの相**＝

> **おなじ音でそろえると、リズムと「つぎもこう来る」の期待が生まれる。さいごの一行がその期待を裏切ると、笑いがおきる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> どうして、さいごの一行で、ふきだしてしまう？——おなじ音でそろえてから、さいごだけ裏切ると、なにがおきる？

## 5オペレータの一口お笑い運用

| Op | 実装 |
|---|---|
| 同 | 同じ型（韻の連打＋オチ）で音を替える（です→さい→とって） |
| 逆 | 読み手として**オチを指さす**（どの行で笑いがおきた？）／行末の音の**そろい・はずれ**を指さす |
| ＋α | 制約追加：韻は4行以上・オチは「韻を守ったまま裏切る」に挑戦 |
| 質的変化 | **オチの発見**＝オチ有無ペア（そろえるだけで終わる版／さいごに裏切りが来る版）——そろえるだけでは詩にならない。裏切りが来て、笑いになる（系列の核） |
| 複合 | 韻4行以上＋オチ＋（できれば韻を守ったまま裏切る）で制作 |

## 縦の鎖

**「破れ」の鎖の完成**：お話①「さいごの一回で型を破る」→視覚詩②「さいごの一行」→なぞなぞ詩③「さいごの比喩が跳ぶ」→**本系列「さいごの一行が期待を裏切る＝笑い」**——同じ原理（反復が期待を作り、最後の一回が破る）の四変奏が、ジャンルをまたいで揃う。俳句①の音数（音の器）→本系列の脚韻（音のそろえ）＝音の鎖も接続。

## 裁定リスト（先生へ・推奨＋根拠＋逆を採る条件）

1. **「買って」の作者確認**——無記名でした。岩井作なら「韻ごと投げ捨てるオチ」の実物として収載したい（「とって」と対になる）。教え子作なら非掲載・構造のみ自作へ。
2. **系列の核（質的変化）＝「オチの発見」（有無ペア）**。**推奨：採用**。根拠＝素材読解2-3（破れの鎖の音版・お話①step5 と同型の器）。
3. **「オチ」という語の扱い**——子どものお笑い語彙として問題文・L2 で使ってよいか（推奨：使う。教室の実感に合う語のはず。逆＝L1/L2 は「さいごの裏切り」に言い換え）。
4. **中心の問い・系列名**（「一口お笑い」そのまま）——磨きは自由。
