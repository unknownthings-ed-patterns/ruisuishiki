## 1. 素材読解A——『楽しい随筆の授業』が言語化する「良い随筆」

本書は実例のあとに必ず「作品のよさ」の評を置く。約25本の実例＋評を読み比べて抽出した不変項（比較が基準を生む）。**実例本文・子ども作例はすべて非掲載**（児童・編著者の著作権）。構造と評の観点だけを借り、教材は自作＋PD＋岩井実物で作る。

### 良い随筆の条件（評からの抽出・出典ページつき）

| # | 条件 | 本書の根拠 |
|---|---|---|
| A1 | **したとおり・見たとおりに書く**（読み手が作者の目でその場に立つ） | 「バスの運転手さん」評（p.204「したことをしたとおりに書いた」）・「道にいた『ネコ』」評（p.143） |
| A2 | **心が動いた瞬間をとらえて書く**（体の動き・比喩で） | 「クバイトでうねかり」評（p.189） |
| A3 | **揺れ動く心を書く** | 「参考作品のよさ」3条件の筆頭（p.73）・「ファミコン」「どうしようかな……」の実例 |
| A4 | **心の変化を出来事・事実との関連で書く**。逆に**事実だけ書いて気持ちを書かない**一文が最も深く感じさせることもある | 「おかあさんと行った買い物」評（p.217-218） |
| A5 | **会話で場面を再現**——「」＝声、（　）＝心のつぶやき、**声の様子（小さな声で／大きな声で）まで書く** | 単元6第2時の記述指導（p.140-141）・「やっぱりお姉さんだね」評（p.210-212） |
| A6 | **詳しく書く場面と省略する場面のメリハリ**——全体は長期間でも「ある日あるとき」を詳しく | 「クリームパン事件」評「工夫された構成と記述」（p.197-198）・「立候補するようになった私」選定理由（p.171） |
| A7 | **時間をおいて客観的にとらえ直して書く**——結びは現在形・体言止めで今の思いを | 「クリームパン事件」評「作者によるこの事件の評価」（p.198）・「おかあさんと行った買い物」評（p.219） |
| A8 | **自分の体験をより大きな世界と関連づける**＝「随筆の本質的な要素」。人に言われるより**自分で気づき、納得する** | 「おかあさんと行った買い物」評（p.215-216） |
| A9 | **状況が伝わる書き出し**・始めと結びの呼応（同じことばで始め、終える） | 「クバイトでうねかり」評（p.189）・p.218の構成論 |
| A10 | **題材は大人が押し付けない**——教育的価値の高い題材（自然愛・親孝行）でも性急に押し付けると逆効果。日常の小さな出来事をほめて、子ども自身につかませる | p.55（最重要の題材論） |

- 指導の型（単元共通）：参考作品を読む→よさを読み取る（**いつ・だれと・何をした・どんな気持ち**の4観点Q&A、p.116）→題材探し（日記・「二枚文集」・1分間スピーチ・体験直後すぐ書く）→構成表→1時間続きで書く→3回読み直して推敲→読み合い（**記述に即して良さを読む**・拍手でたたえる）——ruisuishiki の牧口勾配・読み合いの閉じと同型。
- A1・A5 は日記ユニットで既習（「ました、ました」「」・スローモーション）。A10 はハートマップと合流する。**A3・A4・A7・A8 が随筆固有の未知**＝新系列の核候補。

## 2. 素材読解B——Heart Maps の題材宝庫と「マップ→随筆」の手順

原書の構成＝**20種のハートマップ・テンプレート**。各章が「Introduction（著者の実物エッセイ）→Try This→テンプレートの問いリスト→子どもの作例→Writing Ideas（ジャンル別の広げ方）→Mentor Texts」の型で反復される。

### 20種の一覧（題材の宝庫としての整理）

| 群 | マップ | 中心の問い（テンプレより要旨） |
|---|---|---|
| 入口 | 1 白紙のキャンバス | 心に蓄えた記憶・感情は？　今の自分をつくった人・場所・経験は？ |
| 自分 | 2 書き手としての私／3 読み手としての私 | 書く（読む）ことにまつわる記憶・好き・場所・道具（年度始めと終わりの2回作り成長を比較） |
| 瞬間 | 4 小さな瞬間（v1複数・v2ズームイン）／5 はじめて／6 さいご | 実際に起きた小さな出来事・人生の転換点（はじめて／さいごに〜したとき） |
| 人と名 | 7 家族のキルト／8 わたしの名前／16 尊敬する人 | 家族の物語・伝統・食べ物／名前の由来・呼び名・気持ち／その人の意外な一面 |
| 生活 | 9 ペット・好きな動物／11 わが家と近所／13 特別な場所 | 出会い・習慣・宝物／思い出のある場所・通い道／なぜ特別か・五感の記憶 |
| 心 | 10 感謝／12 願い／14 世界に見たい変化 | 当たり前すぎて見過ごすことへの感謝／自分・人・世界への願い／変えたいこと＋できる行動 |
| 読む・調べる | 15 大好きな登場人物／19 ノンフィクション（探す・掘る）／20 ふしぎに思うこと | 人物の心の変化を出来事とセットで／くわしいこと・愛していること／**知らないことを書け**（疑問が章立てになる） |
| 詩 | 17 詩を見つける場所／18 五感 | 見過ごしそうな小さなもの／五感の細部（write small・show don't tell） |

### マップ→随筆の中核手順（本書全体で反復される型）

1. **集めるのは多め**——マップに描く・書く（チェックリストではなく入口。形の変形も自由）
2. **選ぶのは一つ**——基準は「感情的に響く・心をとらえる・頭にイメージが浮かぶ」項目（p.39）
3. **ジャンルを自問**——「このテーマはどのジャンルで書かれたがっている？」
4. **ズームインして引き伸ばす**——時間を分刻みでスローダウンし、五感の詳細を層づけ（＝日記②スローモーションと同じ手つき）
5. **「So what?（だから何？）——なぜこれは自分の人生にとって大切？」**で意味の層へ（＝随筆①「考えの一歩」と同じ手つき）

→ **Heart Maps の手順は、ruisuishiki が既に持っている道具（集める器・スローモーション・考えの一歩）を「題材発見」の側から束ね直したもの**。詩⑦六つのへや（同じ Heard の Six-Room Poem）が「詩の材料を集める装置」だったのに対し、ハートマップは「随筆の題材を集める装置」——縦の鎖が作者レベルでつながる。

## 3. 新系列の提案——随筆②〜⑤（胚細胞「事実の層と考えの層の往復」の四つの相）

既知→未知の橋の全体図：

```
詩（集める器⑦⑧・物で言う①・音⑥）──┐
お話（筋・人物⑤）──────────┤
日記（時間の背骨・「」・スローモーション）─┴→ 随筆（意味の背骨）
  ①見つけたこと＝考えの一歩（済）
  ②ハートマップ＝題材は心の中にある（集める→選ぶ）
  ③その場にいるように＝事実の層を厚くする（「」と（　））
  ④ゆれうごく心＝心の層を事実とつなげる
  ⑤大きな世界とむすぶ＝意味の層を広げる（第二陣）
```

### 随筆②「ハートマップ（心の地図）」——最優先・入口の次

**胚細胞の相**：

> 題材は、探しに行くものではなく、心の中にすでに蓄えられている。地図にすると見える。**集めるのは多め、書くのは心をとらえる一つ**。選んだ一つに「なぜ大切？」と問うと、随筆が始まる。

**中心の問い（ドラフト）**：

> 「書くことが、ない。」——ほんとうに？　心のなかを地図にかいてみると、なぜ、書きたいことが つぎつぎ見つかる？

（「心をとらえる一つを選ぶ」「なぜ大切？」は Step5〜6 の発見なので問いに書かない＝G1）

**5オペレータ**：

| Op | 実装 |
|---|---|
| 同 | 同じ「マップ→一篇」の型で書き手を替える（岩井→きみ）。本歌取＝岩井のワークシート実物＋そこから生まれた随筆 |
| 逆 | **随筆→マップの逆算**：この随筆は、書いた人の地図のどの項目から生まれた？（六つのへや②の再演・散文版） |
| ＋α | 制約追加＝選んだ一つに「**なぜ、それをえらんだ？**」の一文をそえる（随筆①「考えの一歩」の器を流用） |
| 質的変化 | **全部書く版／一つを選んで書く版のペア**——地図の項目を全部なぞるとカタログで終わる。一つにしぼってくわしく書くと随筆になる（系列の核。Heart Maps の「集める→選ぶ」＋『楽しい随筆の授業』A6 のメリハリと二重に整合） |
| 複合 | 地図で集める＋一つ選ぶ＋スローモーション（日記②）＋考えの一歩（随筆①）で制作 |

**Step 表（スケッチ・背骨確定は裁定後）**：

| Step | kind | Op | 操作 |
|---|---|---|---|
| 1 | comparison | 基本原形 | **岩井のハートマップ実物と、そこから生まれた随筆**を並べて読む——「この随筆は、地図のどこから生まれた？」 |
| 2 | exercise | 同 | 別ペア（自作）で対応づけ（choice：この随筆はどの項目から？） |
| 3 | exercise | 逆 | 随筆→地図の逆算（この随筆を書いた人の地図に**あったはず**の項目はどれ？） |
| 4 | exercise | 同 | **使われなかった項目**さがし（集めるのは多め・使うのは選ぶ＝六つのへや step3 の再演） |
| 5 | comparison | 質的変化 | **全部版／一つ版のペア読み比べ**（核） |
| 6 | exercise | ＋α | 選んだ一つにそえる一文3択（別項目の説明／選んだ項目から立ち上がる一歩○／無関係——①step6 の確立した器・G2） |
| 7 | creation | 同・本歌取 | 自分のハートマップを**紙・ロイロで**作り（ワークシート＝岩井版）、心をとらえる一つを選んで短い随筆（showMentorUpfront） |
| 8 | comparison | 観点抽出 | pickViewpoints（revealedInSeries） |
| 9 | creation | 複合 | 選んだ一つをスローモーションでのばし＋考えの一歩 |
| 10 | creation | 自由制作 | →清書カード→読み合い（「きみの地図で、わたしも思い出した」を返す） |

- **観点候補**：「心の地図から、心をとらえる一つをえらんで書いている」「えらんだ一つが、くわしく書かれている（全部をなぞっていない）」「なぜ大切かが、一歩そえられている」
- **マップの型の絞り込み（推奨）**：入口は岩井実践済みの「**特別な場所**」を主軸に、白紙キャンバス型を自由枠として併記。他の型（はじめて／さいご／名前／感謝／ふしぎ）は「もっと読む・じぶんの地図をえらぶ」で紹介し、歩きながら育てる（薄く生んで解禁で増やす＝条件6）。
- **技術ゲートなし**：マップ記入は紙・ロイロ（六つのへや裁定6と同型。6欄UIも地図UIも作らない）。サイトには完成した随筆を prose 入力。

### 随筆③「その場にいるように（「」と（　））」

**胚細胞の相**：「」が声を、（　）が心のつぶやきを運ぶ。したとおり・見たとおりに書くと、読み手が作者の目でその場に立つ（A1・A5）。

**中心の問い（ドラフト）**：

> 読んだ人は、その場にいなかった。それなのに、いっしょにドキドキして、いっしょにほっとするのは、なぜ？

**5オペレータ・骨格**：同＝同型異材料／逆＝**地の文の説明→「」（　）への書き戻し**（どの文が声になれる？）／＋α＝**声の様子をそえる**（「小さな声で」「大きな声で」——相手を思いやる声まで書く・A5）／質的変化＝**（　）の有無ペア**（声だけ版 vs 心のつぶやき入り版——心の中が聞こえると、読み手が作者になる。核）／複合＝スローモーション＋「」＋（　）＋声の様子。

- 縦の鎖：日記①「」の発見（言ったことをそのまま書く）→ここで**（　）＝心の中のことば**が加わる（言い換え語彙は日記と同じ「心の中のことば」）。日記②スローモーションが事実の層の道具として合流。
- 教材：自作ペアが主力＋岩井実物。（　）と「」の書き分けは『楽しい随筆の授業』第2時の記述指導（p.140-141）が構成の借り先。

### 随筆④「ゆれうごく心」

**胚細胞の相**：心は一方向に進まず、行ったり来たりゆれる（A3）。ゆれは「気持ちのことば」でなく**出来事・会話・様子とつなげて**書くと伝わる（A4）。ときには、事実だけ書いて気持ちを書かない一文が、いちばん深く感じさせる。

**中心の問い（ドラフト）**：

> 心のゆれは、目に見えない。それなのに、読んだ人までいっしょにゆれるのは、なぜ？

**5オペレータ・骨格**：同＝同型異材料（ほしい／言えない・やりたい／こわい）／逆＝**気持ちのことば→どの出来事から生まれた？**（心の動きと事実の対応づけ＝随筆①step3 三層仕分けの発展）／＋α＝気持ちのことば一つを「出来事・様子」で言いかえる（詩①「気持ちのことばのかわりに物の名前」の散文版＝合流）／質的変化＝**ゆれをならした版／ゆれのまま書いた版のペア**（迷いを消すと、心が消える。核）／複合＝ゆれ＋（　）（③の道具）＋**事実だけの結びの一文**（気持ちを書かずに終える・A4後半）。

- 教材：自作ペア主力。PD候補＝枕草子の「心ときめきするもの」系の段（原文PD・現代語訳は自前）等は実装段階で選定。
- A7（時間をおいてとらえ直す・現在形の結び）は本系列の complex／derivation で言葉として扱い、独立系列にはしない（採点できないものを無理に採点しない）。

### 随筆⑤「大きな世界とむすぶ」（第二陣・予約）

**胚細胞の相**：自分の小さな出来事を、より大きな世界（社会の出来事・ニュース）の文脈に置くと、意味が見えてくる（A8＝本書が「随筆の本質的な要素」と呼ぶもの）。意見文への橋（接続語の筋道・両面挙げて結論——p.202-203）。Heart Maps「世界に見たい変化」マップが集める装置として対応。6年生想定。②〜④が歩かれてから背骨化する（先取りしない）。

## 6. 裁定リスト（先生へ・推奨＋根拠＋逆を採る条件）

1. **系列数と順序**＝②ハートマップ→③その場にいるように→④ゆれうごく心→（第二陣⑤大きな世界とむすぶ）。**推奨：採用**。根拠＝①考えの一歩→②題材→③事実の層→④心の層→⑤意味の層、と胚細胞の往復が一段ずつ太くなる。逆＝③と④を統合して3系列にする（ただし「差異は一度に1つ」が崩れ、（　）の装置とゆれの内容が同時に新出になる懸念）。
2. **②の核（質的変化）＝「全部書く版 vs 一つを選んで書く版」**。**推奨：採用**。根拠＝Heart Maps の中核手順と『楽しい随筆の授業』A6（メリハリ）の合流点で、六つのへや「集めるのは多め・使うのは選ぶ」の随筆版として縦の鎖が通る。
3. **岩井実物の新規教材2点のお願い**＝(a) 岩井自身のハートマップ実物（教室で使った「特別な場所」版でよい）(b) その地図の一つから生まれた**短い随筆1篇**（新作。『いつもの八百屋で』の三重使用は避けたい）。逆＝(b) を Fable 自作にする（ただし「先生の実物」の力は好きリスト・六つのへやで実証済み）。
4. **マップは紙・ロイロ運用**（地図UI・多欄入力UIは作らない。サイトは完成文のみ）。**推奨：採用**（六つのへや裁定6と同型）。
5. **中心の問い3本の文面**（②③④・上記ドラフト）——磨きは自由。⑤は背骨化時に。
6. **②のマップの型**＝「特別な場所」を主軸・白紙キャンバスを自由枠、他は「もっと読む」で紹介。**推奨：採用**（実践済み実物を本歌にする mirror 原則）。逆＝白紙キャンバス主軸（Heard の原書順。ただし実物がない）。
