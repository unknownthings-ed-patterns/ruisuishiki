## 0. 冒頭の確定事項（D1〜D7・裁定待ち）

**D1. 章の範囲と節順は本の実際の並びに従う**（写真で確認・C10）。第7章は **p.270〜p.296** で完結（p.269 まで第6章「集合と論理」、p.297 から第8章「図形の性質」）。

> 度数分布表とヒストグラム（階級・度数・度数の合計＝総数の検算・階級幅の選択）→ 代表値（平均値・中央値・最頻値／仮平均のコメント／度数分布表からの代表値＝階級値のコメント）→ コラム「平均値にひそむ落とし穴」→ 四分位数と箱ひげ図 → 箱ひげ図の表す意味（広がりと偏り）→ 四分位範囲と外れ値 → 分散と標準偏差 → データの相関（散布図）→ 相関係数（Step1〜4：偏差 → 標準偏差 → 共分散 → $r$）→ 相関係数の特徴 → データの値の変化（$+a$・$k$ 倍）→ 仮説検定の考え方

**著者の意図（背骨に反映）**：章の入口 p.270 が**この単元の胚細胞をそのまま宣言している**——「データはそのままでは単なる数値の集まりで、そのまま下すのは人間には無理。何らかの判断を与え、私たちを方向に導くために分析する」。そこから **視覚化**（ヒストグラム・箱ひげ図・散布図）と **数値化**（平均値・分散・四分位数・相関係数）の 2 本立てが図で提示される。以後の全節はこの 2 本のどちらか（あるいは両方）であり、章の終わりは「**その要約から判断へ渡る**」（仮説検定）で閉じる。**この構成をそのまま系列の骨格にする**。

**この章に無いもの**：相対度数・累積度数（中学既習として省略）／回帰直線／正規分布・区間推定（数Ⅱ・B「統計的な推測」）／分散の公式形 $\overline{x^2}-\bar x^2$（本は偏差の 2 乗の平均という定義のみ）／標準化・偏差値（明示的な節はない → derivation「もっと深く」と 系6 step10・系8 step10 の**芽**としてのみ扱う）。

**D2. 入力系の拡張は不要**（C1 ゲート通過）。この章の答えはほぼすべて素で数値であり、**現行入力系（プレーン数値・分数・小数・負数・`sqrt`・`multi`）で全部採点できる**。ただし数値であるがゆえの**別種の落とし穴**があり、そちらを設計制約として先に固定する：

| 内容 | 素の答え | 折り方・設計制約 | affordances |
|---|---|---|---|
| 度数・階級値・個数・「○番目」 | 非負整数 | そのまま | プレーン |
| 平均・中央値・仮平均で戻した値 | 有理数 | **割り切れる（または分数で書ける）値を設計する**。循環小数になる組は禁止 | プレーン／分数 |
| 四分位数・四分位範囲・外れ値の境界 | 有理数（$1.5Q$ で .5 が出る） | そのまま。境界値は小数第1位まで | プレーン |
| 分散 | 有理数 | 整数になるデータを設計（$n$ で割り切れるように） | プレーン |
| 標準偏差 | 無理数になりうる | **①分散を平方数にして整数で問う**（基本 step）／**②無理数のまま `sqrt` で問う**（質的変化 step・`answerDisplay` に「$\sqrt{\;}$」表記）。**「約 5.48 と答えよ」型は絶対に作らない**（判定 TOL=1e-6 厳密。丸め小数は不正解になる） | プレーン／`[sqrt]` |
| 共分散 | 有理数 | 分数で書ける値に設計 | プレーン／分数 |
| **相関係数 $r$** | 一般に無理数 | **$r$ がちょうど有理数（$0.9$・$-0.75$・$0$ 等）になるようにデータを設計する**（$s_x s_y$ が有理数になる組を選ぶ）。**「小数第2位まで四捨五入」型は禁止**（原典 p.292 練習5 はこの型だが、厳密判定の当システムでは採用できない）。有理数に折れない場面は $r$ の代わりに**共分散の符号・値**を問う | プレーン／分数 |
| 相関の正負・強弱の判定 | ことば | **番号選択にしない**。「偏差の積が正になる点の個数」「$r$ の値そのもの」に折る（判定の中身を要求する檻） | プレーン |
| 確率（仮説検定） | 有理数 | 分数または割り切れる小数。**「棄却できるか」は番号にせず、「基準を下回る最小の回数」「否定できる基準（%）の最小」に折る** | プレーン／分数 |
| 「この図から確実に言えることの個数」型 | 非負整数 | 個数檻（集合と論理 D2 の型を継承）。乱用しない——**1 ユニットで 2 step まで** | プレーン |

**禁止**：①丸めた小数を答えさせる（$\approx$ の付く答え）②箱ひげ図・散布図の「見た目」を番号で選ばせる③データ列そのものを入力させる。

**この折り方が学びとして効く理由**：この単元は「答えが数値なのに、**その数値が何を捨てた結果か**を分かっていないと読み違える」という構造を持つ。だから採点対象は素直な数値のままでよく、**設計の勝負は値の選び方**にある——「平均は動くが中央値は動かない値の組」「四分位範囲では同じで分散だけが違う 2 群」「散布図では明らかに関係があるのに $r=0$ になる並び」。**C12（必然性の 1 問）がこの単元では全面的に「値の設計」で作られる**。

## 1. ハブ胚細胞と縦の鎖

**ユニットのハブ胚細胞＝「たくさんの数は、そのままでは判断の材料にならない。**要約とは情報を捨てること**——絵に捨てる（視覚化）か、1 つの数に捨てる（数値化）か。何を残し何を捨てたかを知っている人だけが、要約の嘘を見抜き、要約から判断へ渡ることができる」**

数Ⅰハブ「扱えない形を扱える形に書き換える（帰着）」の**判断版**。計算の帰着（数と式）・図形の帰着（三角比）・数え上げの帰着（場合の数）・論証の帰着（集合と論理）に対し、この章は**判断の帰着**——大量の観測を、判断できる少数の数に落とす。そしてこの章だけが「**帰着の代償**」を正面から扱う（平均の落とし穴・階級幅で顔が変わる・外れ値・$r$ が見落とすもの・検定の誤りのリスク）。

- **相A：絵に捨てる（視覚化）** ＝系1（ヒストグラム）・系4（箱ひげ図）・系7 前半（散布図）
- **相B：1 つの数に捨てる（数値化）** ＝系2・系3（代表値）・系5・系6（散らばり）・系7 後半（相関係数）
- **相C：捨て方の法則と、要約から判断へ** ＝系8（変換で要約がどう動くか）・系9（要約を根拠に判断する）

```
小5 平均 e5_mean_01 ✅ ／ 中学 度数分布表・ヒストグラム（既習）
数直線上の点 adv_number_line_01 ✅（重み付き平均）／ 数と式 ✅（2乗・√）／ 関数とグラフ ✅（座標平面）
場合の数 ✅ ／ 確率 ✅（独立の積・反復試行）／ 集合と論理 系7 背理法 ✅
  → 系1 度数分布表とヒストグラム（区切って数えると、分布の形が見える）
  → 系2 代表値（「真ん中」が 3 つあるのはなぜ）
  → 系3 仮平均と階級値（ずらして計算する・代表で代用する）
  → 系4 四分位数と箱ひげ図（位置で切ると、広がりと偏りが見える）
  → 系5 四分位範囲と外れ値（データ自身をものさしにする）
  → 系6 分散と標準偏差（消える散らばりを、2 乗で救い出す）
  → 系7 相関係数（測り方によらない「関係の強さ」）
  → 系8 データの値の変化（要約の数たちは、それぞれ違う変わり方をする）
  → 系9 仮説検定の考え方（背理法の確率版・要約から判断へ）
  → 数Ⅱ・B 統計的な推測（未実装）／大学 推測統計・回帰・機械学習
```

**VISION の鎖への 1 行**：このユニットは「**判断の文法**」——数（数と式）・図形（三角比）・離散（場合の数）・論理（集合と論理）の背骨に対する、**不確実さのもとで結論を出す背骨**の起点。系9 が集合と論理 系7（背理法）と確率ユニットを一点で結ぶ、数Ⅰ・A 全体の**閉じ石**になる。

## 2. 系1：度数分布表とヒストグラム（区切って数えると、分布の形が見える）

- **id 案**: `algebra1_data_histogram_01`
