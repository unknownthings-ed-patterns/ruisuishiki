**D1. 章の範囲と節順は本の実際の並びに従う**（写真で確認・C10）。第1章は p.8〜p.55 で完結（p.56 から第2章「関数と関数のグラフ」）。

> 数の拡張 → 有理数と小数 → 実数と数直線 → 指数法則・式の整理・次数 → 展開 → 因数分解 → 1次方程式と1次不等式 → 2次方程式（因数分解） → 平方完成・解の公式 → 判別式

**この章に無いもの**：平方根の計算（$\sqrt{}$ の簡単化・有理化）・絶対値・対称式・整数部分/小数部分。本章では $\sqrt{}$ は「$x^2=a$ の解」としてのみ登場する（p.45）。したがって旧系列「平方根の簡単化」に対応する節は第1章に存在しない（→ D5）。

**D2. 入力系の拡張は不要**（C1 ゲート通過）。答えが「式」や「範囲」になる項目を、すべて**数値で問える形に折れた**。折り方は下表。原則は trig と同じ「**採点できないものを無理に採点しない・概念は derivation で言葉として扱う**」。

| 内容 | 素の答え | 折り方 | affordances |
|---|---|---|---|
| 循環小数 → 分数 | 分数 | そのまま（循環小数は入力できないので分数が強制される） | プレーン |
| 指数法則・単項式 | 式 | **指数を1つ**／**係数を1つ**問う | プレーン |
| 多項式の整理・展開・平方完成 | 式 | **指定した項の係数を1つ**問う（$x$ の係数・定数項・$p$・$q$） | プレーン／分数 |
| 因数分解 | 式 | $(x+\square)(x+\square)$ の**2数を順不同**で（`solutionSet` の多重集合一致がそのまま効く） | `[multi]` |
| 1次不等式・連立不等式 | 範囲 | **境界値**／**解を満たす整数の最大・最小・個数** | プレーン／分数 |
| 2次方程式 | 複数解 | `solutionSet`（順不同）。無理数解は `[sqrt]` | `[multi]` `[sqrt]` |
| 実数解なし・判別式 | 「解なし」 | **実数解の個数（0・1・2）**／$D$ の値 | プレーン |

**禁止事項（技術的制約）**：`solutionSet` は**順不同の多重集合一致**なので、**順序が意味を持つ組を答えさせない**。$(x+p)^2+q$ の $p$ と $q$ は**別 step で1つずつ**問う。「$b$ と $c$ をカンマ区切りで」のような設計は $b=5,c=6$ と $b=6,c=5$ を区別できず不正解を正解にする。

**この折り方が学びとして効く理由**（先生に確認したい点）：不等式で「解を満たす整数の最大値」を問うと、**不等号の向きを間違えた瞬間に答えが変わる**——この単元の核（負の数で割ると向きが反転する）が採点の対象になる。判別式で「実数解の個数」を問うと、$D$ の符号判断がそのまま採点される。境界値だけを問う設計より核に近い。

## 1. ハブ胚細胞と縦の鎖

**ユニットのハブ胚細胞＝「扱えない形を、扱える形に書き換える（帰着）」**。第1章の全体の弧が、この1原理の3つの相でできている。

- **相A：数の世界を広げる**（引き算ができない → 整数／割り算 → 有理数／対角線が測れない → 実数／2乗して負 → 次の拡張の予告）＝系列1
- **相B：式の見た目を変える**（指数で回数を数える／展開と因数分解は同じ操作の往復）＝系列2・3・4
- **相C：未知の方程式を既知の形に落とす**（積が0に持ち込む／基本形 $\square^2=A$ に帰着させる／帰着の手順を文字のままやると公式になる／ルートの中だけ見る）＝系列5・6・7・8

池田本自身が p.46 に「基本の2次方程式 ⇄ 一般の2次方程式」の対応チャートを置いており、本の構造とハブが一致している。

```
小5 小数と分数（既知）・中学の文字式と1次方程式（既知）
  → 系列1 数の拡張と小数        (横: 小5 小数のわり算・分数)
  → 系列2 指数法則と式の整理     (横: 中学の文字式)
  → 系列3 式の展開             (系列2 の同類項を呼ぶ)
  → 系列4 因数分解             (系列3 の逆読み step を本格化)
  → 系列5 1次不等式            (横: 中学の1次方程式・数直線)
  → 系列6 2次方程式（積が0）     (系列4 を部品として呼ぶ)
  → 系列7 平方完成と解の公式     (系列6 が効かない場合／系列4 の平方の公式)
  → 系列8 判別式               (系列7 のルートの中・系列5 の不等式を呼ぶ)
  → 第2章 2次関数（頂点・グラフ）／数Ⅱ 複素数（実数解なしの先）
```

- 各系列の step1（Socratic）は一つ前の系列か中学既習を指す。`[用語]` は辞書へ、`relatedSeriesId` は概念の**最も下**（最初に教わる系列）へ
- 前提系列が未実装の `[用語]` は素通し degrade で置いてよい

## 2. 系列1：数の拡張と小数

- **id 案**: `algebra1_number_expansion_01`
- **中心の問い（胚細胞）**：「引き算や割り算が『できない』とき、人はなぜ答えをあきらめずに**数そのものを作り足して**きた？——分数と小数が同じ数の別の顔なら、その顔はどこまで書き換えあえる？」
  - 胚細胞的概念：**行き詰まりは、世界を広げる合図**（その世界が四則で閉じているかを問う態度）。転移先：複素数（数Ⅱ「2乗して負」）、無理数の発見、単位や定義域の拡張全般

## 3. 系列2：指数法則と式の整理
