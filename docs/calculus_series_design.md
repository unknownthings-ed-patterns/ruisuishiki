## 0. この単元がユニット群のどこに刺さるか（VISION の縦の鎖）

**上流**：数Ⅰ「関数とグラフ」（変化の割合・平方完成・変域つき最大最小・判別式）／数Ⅰ「数と式」（因数分解・展開）／数Ⅱ「図形と方程式」（直線の方程式・点と傾き）／数Ⅱ「式と証明」（二項定理・恒等式・不等式の証明＝差をつくる）／数Ⅱ「複素数と方程式」（3 次方程式）

**下流**：数Ⅲ（極限・微分法・積分法・回転体）／物理（速度・加速度・仕事）／数Bの数列（区分求積の芽）／大学の解析学

**この単元だけが持つ質的転換**：数Ⅰ・数Ⅱ の関数は**静止した対応表**だった（$x$ を入れると $y$ が出る）。ここで初めて関数が**動くもの**として扱われる——変化の速さそのものが新しい関数になり、その新しい関数から元の関数が復元される。**数（数Ⅰ）→ 式（数Ⅱ前半）→ 動き（微分積分）**という段差の、最初の一段。

## 1. ハブ胚細胞（ユニット全体を貫く 1 原理）

> **比べる幅を 0 に縮めて取り出した「瞬間」を、隙間なく足し戻すと「総量」が返ってくる。**
> 変化の割合は 2 点を比べないと出せない量だったのに、幅を縮めると 1 点の性質になる（微分）。逆に、瞬間の値を足し集めると、もとの量の増減がまるごと出てくる（積分）。**縮めて取り出すことと、足し戻すことは互いの逆向きの操作**であり、だからこそ「傾き」を測るために作った道具が「面積」を計算してしまう。

各系列の中心の問いは、この 1 原理の異なる相を問う：

| 相 | 系列 |
|---|---|
| 幅を縮める（比較 → 1 点の性質） | 1 |
| 点の答えを関数に昇格させる | 2 |
| 傾きを図形の言葉に翻訳する | 3, 4 |
| 局所と大域を区別する | 5 |
| 未知を「グラフの高さ」に翻訳する | 6 |
| 巻き戻すと定数が失われる | 7 |
| 差を取ると失われた定数が消える | 8 |
| 足し戻した総量が面積になる | 9, 10 |
| 縮めることと足し戻すことが逆である | 11（要石） |

**ハブへの接続の書き方**：各系列の derivation の「ここが胚細胞」で、その系列がハブのどの相かを 1 文で言い切る。系列 11 は「ハブそのものを問題にする系列」と明示する。

池田本の実物で **p.215（扉）〜p.276（章末）**、p.277 から第7章「数列」であることを柱で確認済み。カタログの `topicGroup` は既存の **「微分・積分」**（指数関数・対数関数の直後・数列の前）を維持する——池田本の並びと一致している。

### D2. 入力系ゲート（C1）——**拡張は不要**

答えの生の型を全部洗い出した結果、**現行の入力系（数値・分数・`[sqrt]`・`[pi]`・`solutionSet`・`answerDisplay`）で全部折れる**。拡張の提案はしない。

| 生の答えの型 | 現行で採点できるか | 折り方 |

| 平均変化率・微分係数・極値・最大最小 | ✓ そのまま数値（分数あり） | — |
| 定積分の値・面積 | ✓ そのまま数値（**分数が主役**） | — |
| **導関数 $f'(x)$**（式） | ✗ | **指定した項の係数**（1 step 1 係数）。式と証明の C1 追補5 がそのまま効く |
| **接線の方程式**（式） | ✗ | **傾き**と**$y$ 切片**を**別 step** に割る（C1 追補4：順序対を 1 問で答えさせない） |
| **不定積分**（式＋$C$） | ✗ | 指定係数。条件つきで $C$ を確定させた後の**指定した点の値**も可 |

| 極値をとる $x$ が 2 つ／接線が 2 本 | ✓ `solutionSet`（順不同・多重集合一致） | この単元の追い風。**片側の値だけ**を答えさせる限り安全 |
| 円すいの体積・$\pi$ を含む値 | ✓ `[pi]` + `answerDisplay` | 系列9 step10 のみ |
| 1/6 公式の無理数交点 | ✓ `[sqrt]` + `answerDisplay` | 値の設計で有理数に寄せるのが基本。無理数を使うのは系列10 step9 の 1 問だけ |

**C1 追補 2（厳密一致で採点できる値に設計できるか）をこの単元で通した結果**——ここが実装の最重要制約：

- **定積分の答えは分数になるのが普通**（$\frac{26}{3}$ 型）。分数入力は既存評価器で通るので問題ないが、**循環小数でしか書けない値を「小数で」答えさせない**。`answerDisplay` に既約分数を置く
- **面積を「約 ◯◯」で答えさせない**（TOL=1e-6 厳密）
- **極値・最大最小は整数か簡単な分数に落ちるよう、係数を先に設計する**。3 次関数は $f'(x)$ が因数分解できる係数を選ぶ（$f'(x)=0$ が有理数解をもつ）
- **微分係数を定義（極限）で求める step では、$h$ の 1 次の係数が整数になる**ように

厚み基準（単独で 5 オペレータ・10 step を満たせるか）で判定した。この章は**過去最大のページ数**（62 ページ・整数は 39、式と証明は 26）で、微分パートと積分パートがそれぞれ独立した単元の厚みを持つ。
