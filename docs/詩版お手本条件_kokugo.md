## 抽出の方法

1. 4系列を並べ、全系列に共通して**効いている**構造を不変項として言語化（自分の設計意図でなく、実装物から拾う）
2. Grok の不変項8本と突き合わせ（一致＝条件の芯・不一致＝検討）
3. 「揺れ」7本を一つずつ裁定：**欠陥側の揺れ**（→条件で禁止）か**多様性**（→条件は縛らない）か
4. 俳句7条件を一条ずつ通し、詩に**そのまま通用する／一般化が要る／通用しない**を判定
5. 監査で見つかった欠陥（B-1〜3・M-1〜2）を「次の系列で同じ穴を開けない」条項に変換

## 詩版お手本条件（全文）

### 条件1　中心の問い＝胚細胞の一相を「なぜ」で問う

共通胚細胞「小さな装置（型・語・配置）が大きな意味の体系を呼び出す」の、その系列の装置の相を、**操作の列挙でなく「なぜ」の1文**で問う。①切って置くと遅くなるのはなぜ／②見ただけで伝わるのはなぜ／③名前を言わずに当てられるのはなぜ／④さいごの一行でふきだすのはなぜ。**中心の問いは常時表示の帯なので、後半 step の発見（名指し・観点）をネタバレさせない**（日記①の教訓：4種の列挙を問いから落とした）。

> 根拠：Grok 不変項1「4系列とも装置の『なぜ』を一文で問う。ここが一番きれいに揃っている」。俳句条件1がそのまま通用（Grok も同判定）。

### 条件2　5オペレータ網羅・質的変化＝系列の核＝「さいごの一回」の差異ペア

5オペレータ（同・逆・＋α・質的変化・複合）を系列単位で網羅し、差異は一度に1つ。**質的変化の核は「さいごの一回（結び・一行・オチ・切る位置）の差異ペアの読み比べ」で立てる**——①切る位置違い2版／②一行の有無／③跳びの有無（結び違い）／④オチの有無。原理は「**最後の操作が、読む速さと意味を変える**」（破れ型〔②③④〕も減速型〔①〕もこの一般形で覆う）。**逆オペレータは「読み⇄書きの向きの交換」を必ず一度**（詩→一文に戻す／当てる→出題する／オチと音のはずれを指さす）。

> 根拠：Grok 不変項3・8。俳句条件2の「質的変化＝核」を一般化（俳句の「切れ」から「さいごの一回」へ——Grok「①を取り残さない一般形」の提案を採用）。

### 条件3　ヒント3層の規律——L1 比較指さし・L2 差異1つ・L3 模範文側

- **L1**＝技法名ゼロの比較の呼びかけ。**手順を日本語に言い換えた解説もゼロ**（「／の数を数える」型は違反——監査 M-2）
- **L2**＝差異を1つだけ名指す。**除外の手順（「〜は外れる、のこるのは？」）は L2 の仕事の上限を超える**——除外の言語化は L3 へ（監査 B-1・B-2 の教訓・Grok 設計所見）
- **L3**＝模範文側の作り方の言語化（技法名・`[用語]` 解禁・**読みを添える**〔脚韻（きゃくいん）〕）。代筆＝完成作品の提示は L3 でも絶対なし（G10）。**L3 が教材について言う事実（比喩の数・行の内容・「〜にしかおきない」）は、教材の実物と突き合わせて真であること**（監査 B-1：しゃぼんだまの教訓）
- **言い換え語彙表は系列ごとに増築**する（切るところ・文字のすがた・たとえ・そろえる音…）。教室語の例外（「オチ」は L2 可・「ひゆ」は問題文と L3）は**裁定して表に明記**。俳句の一表制は詩では成立しない——表に無い同義語の素通りが監査の本体になる

> 根拠：Grok 不変項5・比較所見「俳句条件3の通用しない部分」・M-2・B-1/B-2。

### 条件4　牧口勾配の10step骨格と、閉じの文化

読み比べ（入口・声に出す）→ 識別 → 最小対または指さし → 逆 → 質的変化（核）→ **＋αのルール3択**（候補は「そろえた・説明・無関係」の器＝**判定はルールのみ・よい答えは無数**、を問題文の括弧で渡す——G2 の避難所）→ 本歌取（**showMentorUpfront**・元の作品が最初から見える）→ 観点抽出（pickViewpoints・**revealedInSeries で当該系列から解禁**）→ 複合（**前系列の道具を1つ、名指しで合流**——気持ちのことばを使わない、等）→ 自由制作（清書カード→**読み合いの閉じ**。音の装置の系列は「声に出して」を問題文・完了画面で一貫）。

> 根拠：Grok 不変項2・4・7。俳句条件4の直訳＋詩4系列で安定した「＋α3択の器」を条項に昇格。

### 条件5　教材＝自作が天井・一点差ペア・choice は一意

- 自作教材が系列の天井。**比較ペアは対比変数の制御が命**（一点差——感想語1語・一字・一行・結びだけ）
- **choice は、答えを見ずに問題文と教材だけで自力で解き、「別の選択肢も正解だと言い張れないか」を確かめてから載せる**（国語は答えの一意性が数学より脆い——監査 Blocker 3件はすべてこの型）。「その物にしかおきない」を主張するときは、**教材内の他の比喩・他の文と突き合わせて真**であること
- 入れ替え・移動を指さす問題は、**指す対象が一つ**になる設計に（二文の入れ替えは二択になる——監査 B-3）
- 判定の問いはルール型で書く（「◯◯になっているのはどっち」のジャンル名判定にしない——監査 M-1）

> 根拠：監査 B-1・B-2・B-3・M-1 の直接変換。俳句条件5の「比較ペアは一点差・自作が主力」を継承し、音数検算（countMora・ユニーク7〜9句）は**詩では非適用**（④の行末かな比較だけが親戚として将来候補）。

### 条件6　権利の三本柱と、読者の想定

- 本歌・実物＝**PD または licensed**（作者実名＋許諾日を sourceNote に）。保護中の作品は**本文・図版とも載せず書誌のみ**（視覚作品は部分引用が立たないため引用ベースも使わない）。全件 sourceNote＋rights・**PD 判定の根拠を文書化**（日本人=1967年以前没／外国=没年+50×初出1952-04-28以降×延長で復活せず。俳句の「戦前没」条項は詩の拡張判定に置き換わる）
- **読者は不特定多数**（子どもも大人も・岩井の教え子に限らない）。「きみの先生」のような特定関係を前提にした語りをしない。実物の作者は実名＋さん（古賀さん・白谷さん・岩井さん）で、系譜として語る

> 根拠：俳句条件5の権利部を詩①の拡張判定で更新（Grok 比較所見と同判定）。読者想定は 2026-08-21 岩井裁定を条項化。

### 条件7　装置に従う表示・図・出典

- **表示・入力は、その装置が必要とする向き・空白・間を保持する**（視覚詩＝縦書きグリッド・全角スペースが作品・字間詰め／オチ前の空行＝間／音数メーター非適用）。俳句の「縦書き1列 nowrap」は視覚詩では形を殺す——装置ごとに置き換える
- **作品自体が図である系列は、図マーカーを使わない**（宣言もしない）。図を置くのは装置が図を要する場合のみ（①の step1・質的変化）
- **型の出典クレジット**（創作遊び・詩法の着想元＝アイデアは自由・クレジットは正確に）＋**作家の風景**（系譜——百年の歴史・実物の作者・教室へ届くまで）＋「もっと読む」（G4）

> 根拠：Grok 不変項6・比較所見「俳句条件6の通用しない部分」。②の縦書き入力・④の空行保持・③④の図なし判断を条項化。

## 揺れ7本の裁定（Grok 比較所見より）

| 揺れ | 裁定 |
|---|---|
| 図（①のみマーカー） | **多様性**（条件7に「装置が要する場合のみ」と書いた） |
| 逆の回数（④は2回） | **多様性**（条件2は「必ず一度」＝下限のみ） |
| 最小対の中身（③だけペアでない） | **欠陥側**——B-1 の温床。条件5「choice は一意」で禁止 |
| 本歌の出どころ（PD訳／licensed実物） | **多様性**（条件6の三本柱に両方が入る） |
| 入力方向（②のみ縦書き） | **多様性**（条件7「装置に従う」） |
| 技法名の例外（ひゆ・オチ） | **多様性**——ただし条件3「裁定して表に明記」を義務化 |
| step4 の問い方（④だけジャンル名判定） | **欠陥側**——M-1。条件5「ルール型で書く」で禁止 |
| 入口の教材が核を先に使う（③ほしくず等） | **保留**——S 裁定（歩いた後）と連動。条件化しない。実walk の感触で「入口は核の装置を使ってよいが、名指しは質的変化 step」を足すか決める |
