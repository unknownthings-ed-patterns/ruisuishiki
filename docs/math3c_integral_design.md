### ここまでの気づき（背骨の種・確定ではない）

- **「巻き戻す」は原典の言い回し**（確認済み）：p.207 精講「微分の公式の『巻き戻し』」が初出、p.210「積分はあくまで『微分の巻き戻し』」、p.211 精講、p.221 の節名「合成関数の微分を巻き戻す」と本文「合成関数の微分を巻き戻す形で」。かぎ括弧つきの名詞形と節名の動詞形の両方がある。→ 数Ⅱ・B 既存題「不定積分——微分を巻き戻す」の扱いは先生に Q（起動プロンプト §2-5）
- **$\frac1x$ の節（p.210〜211）が胚細胞の素材**：「$\int\frac1xdx=\log x+C$ としてしまいたくなりますが、実はこれは正しくありません」＝左辺の定義域（$x\ne0$）を右辺（$x>0$）がカバーできていない → 対数の微分を $\log(-x)$ に拡張 → $\log|x|$。**原典は「冪の公式の $n=-1$ の穴」という言い方はしていない**（p.208・209 の $\frac1{\alpha+1}$ に $\alpha\ne-1$ の断りも無い）。「穴」の見立ては ruisuishiki 側のもの
- **原典が山場の素材を本文で名指している**：p.214「$(e^x+1)^3$ を $e^x+1$ のかたまりと見て $\frac14(e^x+1)^4$」は外れる（$e^x$ 倍のズレ）→「簡単に補正ができるのは『定数倍のズレ』であるときに限る」／p.215「$\sin^2x$ を $\frac13\sin^3x$ と考えてしまうのは、よくある間違い」＝**素朴な読みが外れる型（Q1 の②）**。ただし p.214 の「限る」は〈逆数をかけて直せる〉範囲の断定で、関数倍のズレが「かたまりの微分」なら p.221 の痕跡の道で直る＝**系列をまたいで預けと返済になる**
- **p.205 と p.223 の対比**：$e^{x^2}$ は「単純な関数の組み合わせで書き表すことはできません」（原典自身が範囲を添えている）／$xe^{x^2}$ は痕跡 $(x^2)'$ があるので積分できる。**素材メモの観察で、原典は対比として明言していない**
- **伏線（預け）**：p.212「$\int\tan x\,dx$・$\int\log x\,dx$ はまだ求められていない…置換積分・部分積分を学んだあとのお楽しみ」→ 練11（p.229）・練14（p.239）で返す（実物で確認予定）
- **定数倍のズレの補正**（p.206「定数倍のズレは補正できる」・p.209 の $\int f(ax+b)dx=\frac1aF(ax+b)+C$）は**指定係数に折りやすい**（C1 追補6）。不定積分の答え $\frac1a$ がそのまま数値になる
