## 素材読解——The Seventh Princess の二重構造

1. **贈り物サイクル×4**（前半）：おきさきが屋根から外を見て願う→王が字義どおりに囲いの中へ持ち込む→おきさきはため息。①「春がほしい」→五万人の庭師が花を植える ②「川がほしい」→大理石の噴水 ③「人々がほしい」→市場の女六人を連れてくる（→六人の乳母に）④「鳥がほしい」→鳥刺しに捕らえさせる。**「ことばのとおり」と「ねがいのとおり」のずれ**が、同じ型の反復で濃くなっていく（おきさきの本当のねがい＝柵の外へ出ること・一度も言えない）。
2. **六と一の対比**（後半）：六人の金髪のひめ＝六人の乳母＝六羽の白鳥——毎日同じだけ髪を洗われ、とかされる。七番めは黒髪・赤いハンカチ・母が屋根の上でこっそり世話。「**髪がいちばん長い娘が女王になる**」→測ってみると**六人はそっくり同じ長さ＝きめられない**→七番めはハンカチを外すと**短く切ってある**（母が毎日はさみで）→王「どちらが女王になるにせよ、おまえではない！」→**七番めは赤いハンカチを結び直し、丘へ川へ草原へ市場へ走り出る**（母のねがいの実現）。鳩とぼろ服の従者がついて行く。
3. **世界の王子とぼろ服の従者**：「世界はいろいろでできている——話す者と黙る者・持つ者と持たざる者・中にいる者と外にいる者」——結びの一行「it takes all sorts to make the world, those that are in and those that are out」。
4. **結末の三行**が三人の行く末を対比：六人は白鳥のように白髪になるまで髪を洗われ続け・世界の王子は目を伏せて待ち続け・七番めは外へ走る——**勝ち負けの定義の反転**（王冠でなく自由が勝ち）。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：

> **くりかえしは、そろえるためでなく、くらべるためにある。同じ型で四回こたえると「ことば」と「ねがい」のずれが見え、六人がそっくり同じにそろうと、なにもきめられなくなる——ちがう一つだけが、話を動かし、ほんとうのねがいをかなえる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> みんなが、同じだけたいせつにされて、そっくり同じになったとき——お話は、どうしてうごけなくなる？　そして、だれが、うごかす？

## 5オペレータ運用

| Op | 実装 |
|---|---|
| 同 | 贈り物サイクルの型（願い→字義のこたえ→ため息）を型として読む・使う |
| 逆 | **こたえ→ねがいの逆算**：王さまのこたえから、おきさきのほんとうのねがいをたどる（ずれの発見） |
| ＋α | 制約追加＝**ちがう一つを一個だけ**（そろった六つに、ちがいを一つしのばせる書き方） |
| 質的変化 | **そろいの決定不能**＝六人の髪がそっくり同じ長さ→きめられない／ちがう一人→話が動く（系列の核） |
| 複合 | 願い→字義のこたえの反復＋そろった六つとちがう一つ＋絵で終わる結び、で制作 |

## 縦の鎖

お話①「もし」（同×3→さいごの一回の破れ・おくさまの部屋）→**④破れの意味論**（破れが勝ち負けの定義をひっくり返す）。①の「もっと読む」で予約されていた本歌がここで満期。②二項式（遠さ）・③書き換え（骨）→④は「そろい」と「ちがい」＝**差異の価値**を正面から。⑧好きリスト（その人にしか書けない一行）・随筆①（発見）→「ちがう一つ」の系譜。数学＝**そろったデータからは決められない・分散が情報**（統計ユニットとの遠い響き——L3では言わず作家の風景の含みに）。

## 裁定リスト（先生へ・推奨＋根拠＋逆を採る条件）

1. **系列名**——「七番めのひめ（そろった六つと、ちがう一つ）」を推奨。逆＝「ちがう一つ」を伏せたいなら「七番めのひめ」一語。
2. **核**＝そろいの決定不能（六人の髪が同じ長さ→きめられない・ちがう一人が話を動かす）。推奨：採用。
3. **引用箇所2つ**——①贈り物サイクル（春）②測る場面。推奨：この2箇所（ずれの型と核の場面）。
4. **自作見本の型**——「そろった六つと、ちがう一つ」のミニ話（Fable新作）。
5. **中心の問いの文面**（上記ドラフト）——磨きは自由。
6. **結末の扱い**——七番めが「外へ走り出る」結びまであらすじで見せる（勝ち負けの反転が胚細胞の半分のため）。推奨：見せる。
