**D1. 章の範囲と節順は本の実際の並びに従う**（写真で確認・C10）。第6章は **p.246〜p.269** で完結（p.245 まで第5章「確率」、p.270 から第7章「データの分析」）。

> 集合（∈・⊂・部分集合・空集合）→ 集合の表し方（内包表記＝関係代名詞）→ 共通部分と和集合（「または」の日常語とのずれ）→ 補集合と全体集合 → ド・モルガンの法則 → 命題と条件（真偽・反例・「ならば」は一方通行・コラム「逆は必ずしも真ならず」）→ 条件と集合（p⇒q ⟺ P⊂Q・否定）→ 対偶（逆・裏・対偶・包含の逆転）→ 条件についてのド・モルガン → 必要条件と十分条件（十分＝そうであれば OK／必要＝そうでなければダメ）→ 背理法（あみだくじ・対偶との使い分け・√2）

**著者の意図（背骨に反映）**：この章の核は「**条件（ことば）と集合（もの）の表裏一体**」（p.258）。前半で集合の絵の語彙（含まれる・重なり・合わせ・外側）を渡し、後半の論理（ならば・否定・対偶・必要十分）を**すべて集合の絵に翻訳して**説明する。ド・モルガンは集合で 1 回・条件で 1 回、二度通る。証明法（対偶・背理法）は章の頂点。この「絵に翻訳すれば目で確かめられる」構成をそのまま系列の骨格にする。

**この章に無いもの**：要素の**個数** n(A∪B) の計算（場合の数・系3 包除原理の縄張り——本章は集合そのものを求める）・「すべて/ある」の量化子の否定（新課程で扱いが薄い・本章に節なし→derivation の「もっと深く」でのみ触れる）・二項関係や写像（大学）。

## 1. ハブ胚細胞と縦の鎖

**ユニットのハブ胚細胞＝「あいまいなことばを、判定基準の明確な『ものの集まり』に翻訳する——『ならば』は含まれる、『かつ・または・でない』は重なり・合わせ・外側。ことばの真偽で迷ったら、集合の絵の包含判定に帰着させて目で確かめられる。そして直接示せない結論には、反例 1 つ・対偶・矛盾という**裏側から回る道**が用意されている」**。

数Ⅰハブ「扱えない形を扱える形に書き換える（帰着）」の**ことば版**。計算の帰着（数と式）・図形の帰着（三角比）・数え上げの帰着（場合の数）に対し、この章は**論証の帰着**——「ことば ⇄ 集合の絵」の翻訳表を渡す。

- **相A：集合の絵の語彙**（要素・部分集合・∩∪・補集合・ド・モルガン）＝系1〜3
- **相B：ことばを絵に翻訳する**（命題・反例・逆裏対偶・必要十分）＝系4〜6
- **相C：裏側から回る証明**（対偶証明・背理法）＝系7

```
小学校 整理と分類・「なかま分け」
数Ⅰ 数と式（ハブ「帰着」・実数の分類・1次不等式）✅
場合の数 系3（引き算で数える・ベン図）✅ ／ 確率（事象＝集合の芽）✅
  → 系1 集合と部分集合（∈ と ⊂——階層のことば）
  → 系2 共通部分と和集合（「かつ」「または」を目で見る）
  → 系3 補集合とド・モルガン（「でない」は世界を裏返す）
  → 系4 命題と反例（「ならば」は一方通行）
  → 系5 逆・裏・対偶（否定してひっくり返すと真偽が保存される）
  → 系6 必要条件・十分条件（矢印の向きが名前を決める）（旧 algebra_necsuf_01 吸収）
  → 系7 背理法（わざと仮定して、矛盾で倒す）
  → 数Ⅱ 式と証明（前方）／軌跡と領域の同値変形 ✅（横）／大学 論理学・集合論
```

**VISION の鎖への 1 行**：このユニットは「**証明の文法**」の最下段——以後のすべての単元の論証（同値変形・存在と非存在・必要十分の吟味）がこの上に載る。数の背骨・図形の背骨・離散の背骨に対する、**論理の背骨**の起点。
