## 素材読解——「好きリスト」の仕掛け

1. **リスト＝詩の器**：「〜が好きです」をならべるだけで詩になる。**ローフロアが全系列中で最も低い**（リストなら誰でも書ける——ワークシート方式の哲学の極点）。しかも読むと**その人が立ち上がる**（岩井のリスト=電動自転車→紅葉→スヌーピーのスタンプ→ブロッコリー→米津玄師→原神→**カント**——選択とならびが人物を描く）。
2. **谷川の詩の装置**（スライドで確認・本文非掲載）：①具体の形容（「ノルウェーで買った木のトング」——ただのトングではない）②**行末の変化**（好きです／好きだし／好きだなあ／好きかもしれない／**あ ジョニー・デップ好きです**——思い出した瞬間の肉声）③ならべの動き（物→風景→人→最後は「嫌いなもの（と人）のこと何故嫌いか考えるのも」＝**最後の一行が跳ぶ**）。
3. **岩井の実物が同じ装置を実演**：「リサイクルショップで買った日本製の電動自転車」「ツユクサのサファイアみたいな青」（具体）／好きです・好きだし・好きだなあ・好きですね（行末）／「あ ジェームズ・スチュアートも好きです」（あ、の行）。
4. **推敲指導の実物**（教え子の推敲前後ペア・非掲載・構造のみ）：先生のコメント=①書くじゅんばんの入れかえ ②「好きです」の言い方をいろいろに ③具体化の問いかけ（「↑なにアイスのにおい？→○○アイスのにおいが好きです」）——**あすこま記事の指導二本柱（行末の単調回避・形容の具体化）と同じ**で、推敲後の作品で実際に行末が変化し具体が増えた＝**指導→推敲の因果が1件分追跡できる**（犬のペペA/B・ふしぎなめがねに続く一次資料）。
5. **あすこまの「思わぬ効用」**：授業開き・関係づくり（読み合いで互いの好きを質問し合う）・保護者が喜ぶ・作家の時間のカンファランス資料になる——ruisuishikiでは**閉じ=読み合いで「聞きたくなったことを質問し合う」**に変換できる。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：

> **「好き」をならべるだけで、詩になる。行末の小さな変化が肉声になり、具体の形容がその人だけの好きにする。リストは、いちばん低い入口から、その人を立ち上がらせる詩の器。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> 「好き」を、ただ、ならべただけなのに——どうして詩になって、書いた人の顔まで見えてくる？

（行末の変化・具体の形容は Step4・5 の発見なので問いに書かない＝G1）

## 5オペレータ運用

| Op | 実装 |
|---|---|
| 同 | 同じ「好きリスト」の型で書き手を替える（谷川〔書誌〕→岩井→きみ）。本歌取＝岩井のリスト |
| 逆 | **リスト→人の逆算**：このリストを書いたのは、どんな人？（選択とならびから人物を読む——なぞなぞ③・ゆめ⑤の再演） |
| ＋α | 制約追加＝**具体の形容**（ただの「ぶどう」でなく「おばあちゃんの家でとって食べる、皮ごとのぶどう」）・**「あ」の一行**（思い出した瞬間の肉声） |
| 質的変化 | **行末の変化の有無ペア**＝全行「〜が好きです。」版／行末が動く版——単調がやぶれると、声が聞こえる（系列の核。教え子の推敲前後がこの実証） |
| 複合 | ならべの順番（にた好きをまとめる・最後に置くものを決める）＋具体＋行末の変化、で制作 |

## Step 表（ドラフト・裁定待ち）

## 言い換え語彙表への追加（L1/L2 用）

## 縦の鎖

⑦6つのへや（集めてならべる器・くりかえしの回数）→**本系列（ならべ自体が詩・くりかえしの中の小さな変化）**——「回数のダイヤル」の次は「行末のダイヤル」。①5秒の詩（気持ちのことばを消して具体で言う）→Step2の具体の形容。なぞなぞ③・ゆめ⑤（当てっこ・逆算）→Step3のリスト→人。随筆①（メモ⇄随筆の境）→**リスト⇄詩の境**（同族の器・「事実だけだとメモ」の詩版）。俳句①の字余り（定型の中の破れ）→行末の変化。**随筆②ハートマップ（予約）との強い親戚**——好きリスト=心の地図のリスト版・授業開きの自分軸。

## 裁定リスト（先生へ・推奨＋根拠＋逆を採る条件）

1. **系列名**——「好きリスト」そのまま推奨（実践名であり谷川の詩の題でもあるが、**題名に著作物性はない**〔5びょう日記の前例〕。カタログの括弧は付けず一語で）。
2. **岩井「好きリスト」の掲載許諾と固有名**——licensed でサイト掲載してよいか。固有名（スヌーピー・ジェームズ・スチュアート・米津玄師さん・サカナクション【？表記=サナクション】・ミホヨ・原神・ぷちにゃ・モンベル・ヘリーハンセン・カント・グリムグリム・スクリーミング・ティー・パーティー・山之端光一さん等）は**事実の言及として著作権・商標上問題なし**が、実在の人名（山之端さん等・知人であれば）だけご本人の心情面をご確認ください。
3. **谷川の詩の扱い**——本文非掲載・書誌のみ（『すき好きノート』アリス館2012）・作家の風景で「谷川俊太郎さんの『好きリスト』という詩から教室に届いた」と系譜を語る。2024年没に触れるかどうかもご判断を（推奨=触れない・生没年は書誌に含めない）。
4. **実践の系譜の書き方**——「甲斐利恵子さんの実践を、あすこまさん（作文教育の国語の先生）が追試して紹介し、岩井の教室に届いた」+「本物に会う」にあすこま記事への外部リンク。推奨：採用（外部リンクは詩①のpoets.org以来2例目）。
5. **核＝行末の変化の有無ペア**（全行「です。」版⇄行末が動く版——教え子の推敲前後の構造を自作で再現）。推奨：採用。
6. **教え子作品**——非掲載（確立ルール）・推敲の型だけ学ぶ。作家の風景で「教室の子どもたちの推敲に学んだ」と敬意だけ残す。
7. **中心の問いの文面**（上記ドラフト）——磨きは自由。
