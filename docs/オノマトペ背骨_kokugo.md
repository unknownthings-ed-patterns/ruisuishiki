## 素材読解——ようすことばの仕掛け

1. **型A（差し替え）**：白秋「兎の電報」（えっさっさ、えっさっさ、／ぴょんぴょこうさぎが、……）の兎を**うなぎにしたら**——「にょ〜ろにょ〜ろ」に総取り替えになり、まったく違う詩が生まれる（小二の作例）。**動物を替えると、ようすことばがぜんぶ替わる＝ようすことばが、そのものの体と動きを運んでいる**ことの発見。
2. **型B（かけ合い）**：地の文（様子の説明）とようすことばを**交互に**置き、二人で読む——おさる（ウッキッキー）・ホタル（ふわふわパ！／ピカピカピカ）・鮎（すーいすい）・へび（く〜ね　くね）・にわとり（コケコッコー）・うま（ヒヒーン・ぱっかぱっか）・カエル（てくてくぴょん）。**ようすことば行は「体の音」係、地の文は「場面」係**——二つの声のかけ合いが、動きを立ち上げる。
3. **場面が変われば音も変わる**：カエル（教え子作）——てくてくぴょん…「あれ地面なくね　ポチャ」／ホタル——数がふえるごとに読む人もふやす群読。**音は場面に反応する**（オチ・展開も作れる＝④一口お笑いの親戚）。
4. 白秋の原詩自体が「えっさっさ」の反復＋物語（郵便配達）——**オノマトペの反復が推進力**になる構造。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：共通胚細胞の**ようすことばの相**＝

> **ようすことばは、そのものの体と動きを運ぶ。とりかえれば詩がまるごとうまれかわり、地の文とかけ合わせれば、動きがその場で立ち上がる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> 「ぴょんぴょん」「すーいすい」——音だけなのに、どうしてそのものの体と動きまで見えてしまう？——ようすことばをとりかえたり、地の文とかけ合わせたりすると、なにがおきる？

## 5オペレータ運用

| Op | 実装 |

| 同 | 同じかけ合いの型で動物を替える。本歌取＝白秋「兎の電報」の**差し替え**（うなぎの電報の遊びそのもの） |
| 逆 | **音→本体の逆算**：ようすことばだけからだれか当てる／場面→音を選ぶ（書く向き） |

| 質的変化 | **ようすことばの有無ペア**＝地の文だけ版／かけ合い版——ようすことばを抜くと、動きと体が消える（系列の核） |
| 複合 | かけ合い形式＋音の差し替え＋場面に反応する音、で制作 |

## 縦の鎖

俳句①の音数（音の器）→④脚韻（そろえる音）→**本系列（ようすことば＝意味を運ぶ音）**——音の鎖の三本目。日記②の「音のことばで時間を刻む」（カナブンのブブブブッ）が先行の合流先。④のオチ（場面の反転）→本系列の「場面に反応する音」（ポチャ）。
