## 素材読解——「見つけたこと」の仕掛け

1. **寺田寅彦『柿の種』＝発見作文のお手本の宝庫**（1935年没＝戦前没PD・全文掲載可・短章は俳誌「渋柿」掲載の身辺スケッチ＝子どもの発見作文と同サイズ）：
   - **スウスウ雲**（大正9年12月）：気象学者は cirrus・巻雲と名づける／「私の子供」は無視してスウスウ雲と命名——**同じものでも、見る目がちがえば発見がちがう**。命名＝発見のいちばん小さい形
   - **子猫**（昭和3年1月）：ふざけて噛む相手と舐めるだけの相手の観察→「親しみの深いものには噛みつき、薄い相手には舐めるだけ」——**観察からきまり（ルール）を見つける**
   - **コスモスと蟻**（大正10年11月）：枝の先端に蟻が二、三匹（事実）→高さは蟻の身長の数百倍・人間なら数千尺（考え・くらべ）→「どうしてかぎつけるかが不思議である」（**問いで終わる**）——**事実→考え→問いの三層が一篇の中に見える**
   - 嵐の朝の銀杏（大正10年8月）：嵐に乱される木々が「巨人の手を振るように」→天と地が笑ったようにげらげら笑った——発見が気分まで変える（もっと読む候補）
2. **岩井「いつもの八百屋で」＝発見の階段**（一月三十一日（土）・licensed・**日記②「本物に会う」に既掲載の同篇**＝裁定4で二重使用確定）：①長く買い物するうちにブロッコリーの見分け方（つぼみがかたく空洞でない）がわかってきた→②店員さんは箱から出す瞬間に見分けている→③その店員さんがさっと手渡してくれた＝「きみ、質の高いブロッコリーがわかるのだと思う。このブロッコリーがいいよ」の合図だった——**発見が階段になり、さいごの発見は「人の目」まで届く**。日記の目で読めば日記、随筆の目で読めば随筆——ジャンルの目の読み替えの実物
3. **『楽しい随筆の授業』の定義**（p.10・クレジットのみ・本文非掲載）：随筆＝「身近に起こったこと、見たこと聞いたこと、経験したことなどをきっかけに、自分のものの見方・考え方、生き方などを見つめ直したり深めたりする」＋記述指導＝**出来事と説明（考え）を分けて書く**・心のつぶやきは（　）に。子ども作例「道にいた『ネコ』」（永井勇太）＝非掲載・構造のみ
4. **ハートマップ**（ジョージア・ハード Heart Maps・随筆②以降の集める装置＝詩⑦6つのへやの親戚・器の鎖）：本系列では出さない（本が見つかり文例がそろってから随筆②で）

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**ユニット胚細胞（随筆）**：出来事・観察（事実）をきっかけに、自分のものの見方（考え）を見つめ直す——**事実の層と考えの層の往復**。

**系列①の胚細胞**：

> **小さな「見つけた！」（事実）に、考えを一歩そえると、ただの一日が随筆になる。考えは、あたらしい問いや、つぎの発見をつれてくる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> おなじものを見ても、通りすぎる人と、「見つけた！」と立ち止まる人がいる——見つけたことを書きとめると、なぜ、読んだ人までいっしょに考えはじめる？

（「考えを一歩そえる」は Step5 の発見なので問いに書かない＝G1）

## 5オペレータ運用

| Op | 実装 |
|---|---|
| 同 | 同じ「発見を書く」型で題材・書き手を替える（寅彦→岩井→きみ）。本歌取＝八百屋の「発見の階段」を借りる |
| 逆 | **考え→事実の逆算・三層の仕分け**：この考えは、どの「見つけた」から生まれた？／目で見た事実はどれ？（事実・考え・問いを分ける） |
| ＋α | 制約追加＝**考えの一歩**：事実のあとに置く一文は、事実から立ち上がっていること（言い直し・無関係は不可） |
| 質的変化 | **考えの一歩の有無ペア**＝事実だけ版／考えを一歩そえた版——事実だけだとメモで終わる。一歩そえると随筆になる（系列の核） |
| 複合 | 発見の場面をスローモーションで書き（日記②の道具）＋考えの一歩＋事実と考えを分けて書く、で制作 |

## 言い換え語彙表への追加（L1/L2 用）

随筆・エッセイ→問題文では「随筆（ずいひつ）」を教室語として使ってよい（ジャンル名＝ユニット名。技法名ではない）／考察→「考えの一歩」「考えたこと」／観察→「よく見る」「見つける」／抽象・具体→使わない。L1/L2 で「考察」「教訓」「主題」を出さない。
