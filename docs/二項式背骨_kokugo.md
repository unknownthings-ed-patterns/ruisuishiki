## 素材読解——二項式の仕掛け

1. **ロダーリの核**（4章）：①火花を散らすには電極が二つ必要——単独のことばでは足りない ②**二語には距離が必要**——「馬-犬」は近すぎてだめ（単純な連想）、「犬-たんす」で想像力が動き出す ③偶然に選ぶのがよい（黒板の表裏に書かせる儀式＝期待感）④生まれた物語は**第一次資料**——完成品にするのは書き手の仕事。
2. **6章「もし…なら」＝二項式の変形**：ファンタスティックな仮定は「主語と述語を無作為に結びつける」——つまり**もし文は、二語の出会いを一つの文に折りたたんだもの**。お話①（うそは一つだけ）との合流点。
3. **岩井スライドの二つのきまり**：①二つのことばが出会う（おふろ＋さかな）②もし〜だったら（まちがえても、けさずにどんどん書く）＋例話**『りんと金の魚』**（おふろ×さかな→もしおふろで魚がおよいでいたら→金色に光る魚がダイヤモンドをはき出す——結びは「おふろのそこでしずかに光っていました。」＝絵で終わる。お話①の結びの規律と同じ手）。
4. **村田栄一の理屈**（参考・本文非掲載）：無関係な二語も「形の共通・はたらきの落差」でつながる／はたらきを思いきり誇張する——**遠さがなぜ効くかの教室ことば**。同じタネ「出口はけしゴムだ」から二人の子が**別々の作品**を書いた実例＝「タネは同じでも、お話は分かれる」。
5. **田丸メソッドの展開装置**（参考・文言はオリジナル化）：不思議な言葉を作ったら**「どんなモノ？」「いいことは？」「こまることは？」の三問**で展開する——設定は必ず得と損の両方を生む。教室での実施1件分（ふしぎなめがね・非掲載）が、**この三問の「いいこと/こまること」がそのまま物語の山場と落ちになる**ことを実証している。
6. **系譜の発見**：ロダーリの二項式は、日本の教室で**何度も独立に再発明されている**（村田「AはBだ」→岩瀬「ウソの詩」→田丸「不思議な言葉」→岩井「二つのことばが出会う」）——作家の風景の中身そのもの。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：

> **なんのかんけいもない二つのことばが出会うと、火花のようにお話のタネが生まれる。二語は遠いほどよく、タネはまだお話ではない——「もし」の文にして、筋のとおりに歩かせたとき、お話になる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> 「おふろ」と「さかな」——なんのかんけいもない二つのことばが出会っただけで、どうして、お話がうまれてしまう？

（「遠いほどよい」は Step5 の発見なので問いに書かない＝G1）

## 5オペレータ運用

| Op | 実装 |
|---|---|
| 同 | 同じ二段の型（二語→もし文→お話）で語を替える。本歌取＝『りんと金の魚』 |
| 逆 | **お話→タネの逆算**：このお話のタネになった二つのことばはどれ？（読みから型を見抜く） |
| ＋α | 制約追加＝**三問の展開**（どんなモノ？いいことは？こまることは？——設定は得と損の両方を生む） |
| 質的変化 | **二語の遠近ペア**＝近い二語版（ふつうのできごとで終わる）／遠い二語版（お話が動き出す）——遠さがファンタジーの燃料（系列の核・ロダーリの馬-犬） |
| 複合 | 二語の出会い＋もし文＋うそは一つだけ・筋のとおり（お話①の道具）＋得と損、で制作 |

## 縦の鎖

**お話①「もし」（うそは一つだけ）⇄本系列**——ロダーリ6章が「もし＝主語と述語の二項式」と明言＝**原典が鎖を裏づける**。①はもし文から出発して筋の規律を学んだ。②はもし文の**さらに手前**（二語の出会い）に降りて、タネの作り方を手に入れる——①の学習者は「もし文はどこから来るのか」の答えをここでもらう。ゆめ詩⑤「ゆめのなかでは、ね」（免罪符の親戚）。なぞなぞ詩③・随筆①の当てっこ・発見の交換会→Step10 タネ当てっこ。⑦6つのへや「集めてからえらぶ」→二語を集めて選ぶ手つき。
