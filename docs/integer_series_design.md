## 0. ユニットのハブ胚細胞（VISION の縦の鎖にどこで刺さるか）

> **整数は無限にあるのに、割り算がその無限を有限に畳んでくれる。**
> 割り切れるかで **素数という原子に分解**し、余りで **有限個の箱に分類**し、余りを取り続ければ **必ず終わる**。
> 整数の問題を解くとは、無限の候補を有限の手がかりに帰着させることである。

数Ⅰ・A のハブ胚細胞「**帰着**（扱えない形を扱える形に書き換える）」の **整数版**。第 1 章（数と式）が式の帰着、第 4 章（場合の数）が離散の帰着、第 7 章（データの分析）が判断の帰着だったのに対し、本章は「**無限を有限に畳む**」という帰着の最も裸の形を扱う。10 系列すべてがこの 1 文の異なる現れになる：

| 系列 | 無限をどう有限に畳むか |
|---|---|
| 1 判定条件 | 割り算をせずに、**下の桁 or 桁の和**という有限の手がかりに畳む |
| 2 素数 | 分解は必ず止まる。判定の探索範囲を **$\sqrt N$ まで**に畳む |
| 3 素因数分解 | 無数にある約数を **指数の選び方**という有限の表に畳む |
| 4 gcd・lcm | 2 数の共通構造を **素因数の min / max** に畳む |
| 5 余りの分類 | 無限個の整数を **$b$ 個の箱**に畳む（証明が有限手で済む） |
| 6 互除法 | 手に負えない大きさを、**小さくなり続けて必ず止まる**手続きに畳む |
| 7 一次不定方程式 | 無限の解を **1 つの特殊解＋平行移動**に畳む |
| 8 余りの連立 | 2 つの周期の重なりを **1 つの周期（lcm）**に畳む |
| 9 一般の不定方程式 | 無限の候補を **積の形（約数）と大小**で有限個に絞り、個別撃破 |
| 10 n 進法 | 同じ数を **束ね方を決めて割り算の余りの列**に畳む |

**上下の鎖**：小 5「倍数・約数」／中 3「素因数分解」→ 本ユニット → 数 B 数列（漸化式と整数）・大学の初等整数論／情報（2 進法・暗号）。
**横の橋**（本ユニットの特徴＝数Ⅰ・A のほぼ全章と握手する）：数と式（[因数分解]・共通因数でくくる）／場合の数（[積の法則]＝約数の個数）／集合と論理（[背理法]・[対偶]・[共通部分]・[必要条件]）／データの分析（なし）。

## 1. 確定事項 D1〜D5

### D1. 順序は池田本の節順（C10）

約数と倍数（倍数の判定条件）→ 素数 → 素因数分解 → 最大公約数 → 割り算の基本式（余りによる分類）→ ユークリッドの互除法 → 一次不定方程式 → 一般の不定方程式 → n 進法。
**最小公倍数**は本章に独立の節がない（p.329 は最大公約数のみ）が、学習指導要領の数 A に含まれ、系列 8（周期）が立たないため **系列 4 に内包**する。出典注記にその旨を書く。

### D2. 入力系ゲート（C1）— **拡張は不要**。ただし折り方の指定は厳格に

答えが非数値になる型が多い単元だが、すべて現行入力系（プレーン数値・分数・`solutionSet`・`answerDisplay`）で採点できる形に折れる。C1 追補（非数値を数値の檻に折る 5 つの型）の実運用 2 例目。

| 答えの型 | 現行入力系 | 折り方（**実装はこの表に従う**） |
|---|---|---|
| 個数・値（約数の個数／総和／gcd／lcm／最小の $n$／余り／商） | ✓ プレーン | そのまま。すべて整数＝厳密一致で安全 |
| 素数か合成数かの**判定** | ✗ | **最小の素因数**（素数ならその数自身）＝一意檻／「この中に素数はいくつ」＝個数檻 |
| 倍数かどうかの**判定** | ✗ | 「並んだ数のうち◯の倍数はいくつ」＝個数檻／「□に入る数字のうち最大（または個数）」＝一意檻 |
| 素因数分解の**式** | ✗ | 分解そのものは過程。**指数**・異なる素因数の個数・最大の素因数・約数の個数へ折る |
| **互いに素**かどうか | ✗ | **gcd の値**（互いに素なら 1）。判定が自然に数値になる最良のケース |
| 商と余りの**組** | △ | **別 step に分ける**（順序対を 1 問で答えさせない） |
| 剰余分類による**証明** | ✗ | **鎖の関節の数値**（各ケースの余り・ありうる余りの種類の個数・反例の個数）。1 step 1 関節 |
| 不定方程式の**解の組 $(x,y)$** | ✗ | `solutionSet` は**順不同**なので順序対に使えない。①範囲を与えて $x$ のみ／$y$ のみを別 step ②「範囲内の解の個数」③「条件を満たす最小の正の $x$」 |
| 不定方程式の**一般解の式** | ✗ | 「$n=\square$ のときの値」「範囲内の解の個数」「最小の正の解」「解と解の**差**（＝周期）」 |
| 整数解を**すべて**（片側だけ） | ✓ `solutionSet` | 「$x$ の値をすべて」なら順不同一致でよい。**同じ $x$ に複数の $y$ が対応する形では使わない**（重複が生じる） |
| n 進法の**表記** | ✓ プレーン（数値として） | **数字の並びをそのまま数値として入力**（例：3 進の答えを `1221` と打つ）。`answerDisplay` に右下カッコ付き表記を置き、`questionText` に「数字の並びをそのまま入力」と明示。桁数は 10 桁以内に収める（float 精度と学習者の負担）。**先頭が 0 になる値は作らない** |

**C1 追補 2（厳密一致で採点できる値に設計できるか）の確認**：本ユニットの答えはほぼすべて整数で、丸め・無理数・循環小数の落とし穴が構造的に存在しない。**唯一の注意は「解の組」と「一般解の式」**で、上表の折り方から外れた瞬間に採点不能になる。
