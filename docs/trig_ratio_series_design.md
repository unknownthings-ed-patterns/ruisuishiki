## 0. 冒頭の確定事項（D1〜D7・**2026-07-26 に「推奨どおり」で裁定確定**）

**実装状況**：系列1 `algebra1_trig_tan_01` 実装済（2026-07-26）／系列2〜8 は未実装（進度駆動）。

**D1. 章の範囲と節順は本の実際の並びに従う**（写真で確認・C10）。第3章は **p.102〜p.152** で完結（p.101 まで第2章「関数と関数のグラフ」、p.153 から第4章「場合の数」）。

> 比で測量 → タンジェント → サイン・コサイン → 1つがわかればみんなわかる → 有名角 → 垂線で面積・余弦（鋭角）→ 「90°超でも規則を」→ 単位円による新しい規則（0°〜180°）→ 相互関係 → 図形への応用（面積・余弦の最強版）→ 正弦定理（外接円）→ 応用問題

**著者の意図（背骨に反映）**：多くの本で正弦定理が先だが、本書は**最後**——円（外接円）が要るから。面積・余弦を先に渡し、正弦は「三角形と円の定理」として置く。

**この章に無いもの**：一般角（360°超・負角）・弧度法・三角方程式の本丸・グラフ・加法定理（数Ⅱ）。単位円は **0°〜180° の定義の舞台**として登場し、数Ⅱ「一般角」系列の下側を埋める。

**D2. 入力系の拡張は不要**（C1 ゲート通過）。現行 `answerEval` は数値・分数・`√`・`π`・`solutionSet`（順不同）のみ。答えが「$5\sin 38°$」のような**非特別角の記号式**や「座標の組」「範囲」になる項目は、すべて**数値で問える形に折れた**。

**この折り方が学びとして効く理由**：有名角と相互関係に採点を集中させると、**「表を引く」ではなく「比と座標から導く」**が核になる。鈍角で $x$ 座標だけを問うと、**符号を落とした瞬間に答えが変わる**。正弦定理で $R$ を問うと、**向かい合う角と辺のペアを誤った瞬間に答えが変わる**。

## 1. ハブ胚細胞と縦の鎖

**ユニットのハブ胚細胞＝「直角三角形の辺の比は、大きさによらない形の情報であり、座標（単位円）に移すと鈍角まで同じ言葉で読める」**。数Ⅱのハブ「単位円上の1点」の**下側**——三角形の比として生まれ、座標として開き、一般角へ渡す。

- **相A：比が角の性質になる**（測量・tan／sin・cos／1つから残り・有名角）＝系列1〜3
- **相B：一般三角形へ／定義を広げる**（垂線→面積・余弦 → 単位円で 0°〜180°）＝系列4・5
- **相C：縛りと応用**（相互関係・面積／余弦の最強版・正弦定理＝三角形と円）＝系列6〜8

```
中学 三平方・相似・割合 ✅
数Ⅰ 関数と関数のグラフ（傾き＝tan の言語）✅
  → 系列1 タンジェントと比（測量の入口）
  → 系列2 サイン・コサインと辺の読み
  → 系列3 1つから残り＋有名角          (横: 中学 三平方)
  → 系列4 垂線で面積・余弦（鋭角）       (三平方のアップグレード)
  → 系列5 0°〜180°への拡張（単位円）     → 数Ⅱ 一般角へ
  → 系列6 三角比の相互関係（度数）       → 数Ⅱ 相互関係へ
  → 系列7 面積・余弦の図形応用
  → 系列8 正弦定理と外接円
  → 第4章 場合の数／数Ⅱ 三角関数
```
