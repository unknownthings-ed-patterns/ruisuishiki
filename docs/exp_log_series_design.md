> 指数の拡張（法則をコンパスに）→ 0乗・マイナス乗 → 分数乗 → 無理数乗 → 指数関数のグラフと性質 → 大小比較 → 単調性と最大最小 → 指数方程式 → 指数不等式 → 置き換え（2次化）→ 対数の定義 → 対数の値 → 対数法則 → 底の変換 → 対数関数のグラフと性質 → 対数方程式（真数条件）→ 対数不等式 → 対数の置き換え → 大きな数・小さな数 → 常用対数（桁数・最高位）

**この章の位置づけ**：数Ⅰ「数と式」系列2（指数＝かけ算の回数）が代数側の土台。本章は指数を**実数全体で動く関数**として開き、その**逆対応に名前を付けたものが対数**。グラフのつまみ言語は数Ⅰ「関数と関数のグラフ」および三角関数のグラフ系列から合流する。

**D2. 入力系の拡張は不要**（C1 ゲート通過）。現行 `answerEval` は数値・分数・`√`・`π`・`solutionSet`（順不同）のみ。**`log` トークンは非対応**。答えが「対数式」「一次結合 $a+b$」「範囲」「大小の列」になる項目は、すべて**数値で問える形に折れた**。

| 内容 | 素の答え | 折り方 | affordances |
|---|---|---|---|
| $a^r$・$\log_a M$ の値 | 数 | そのまま1つ | プレーン／分数／`[sqrt]` |
| 大小比較（4数を並べる） | 列 | **いちばん大きい数**／**いちばん小さい数**／「指定した2数で左が大きい？」を 1/0 | プレーン／分数／`[sqrt]` |
| 方程式の解 | 数／複数 | 1解は `answer`。2解は `solutionSet` | プレーン／分数／`[multi]` |
| 不等式の解 | 範囲 | **境界の端**／**解を満たす整数の最大・最小・個数** | プレーン／分数 |
| 底の条件・定義域の可否 | 可否 | 1/0 または定義域の端 | プレーン |
| $a,b$ の一次結合 | 式 | **指定した係数を1つ**／$a,b$ に数値を入れて最終値 | プレーン／分数 |
| 桁数・最高位・小数第何位 | 整数 | そのまま | プレーン |
| グラフの交点・頂点相当 | 座標 | **$x$ だけ／$y$ だけ**を別 step | プレーン／分数 |

**禁止**：`solutionSet` で順序が意味を持つ組を答えさせない。学習者に `log_2 8` のような**対数記法そのものを入力させない**（問題文側に書き、答えは数値）。

**この折り方が学びとして効く理由**：$0<a<1$ の不等式で「解を満たす整数の最大値」を問うと、**不等号の向きを誤った瞬間に答えが変わる**。真数条件つき方程式で「解の個数」を問うと、**捨てるべき解を残した瞬間に個数がずれる**。対数式を答えさせないことで、核（定義・法則・単調性・真数条件）が採点対象に残る。

## 6. 系列5：対数の定義と値
