## 素材読解——書き換えの仕掛け

1. **書き換え（パロディ作文）**＝よくできた物語の**構成（入れ物）はそのまま借り**、6W1H（人・時・場所・道具・敵…）を入れ替える。桃太郎が最適な理由（岩井md）＝昔話の典型パタン（出発・難題・アイテムと味方）が全部入っている。
2. **かぼちゃひめの差し替え表**（三藤の見本・本文非掲載・対応だけ）：ももたろう→かぼちゃひめ・おに→吸血鬼・おにが島→城・刀→十字架・きびだんご→にんにく・犬さるきじ→馬おおかみ大たか——**3回反復の問答定型は保存**。入れ物と中身の境界が一目で見える。
3. **プロップのカード**（三藤版18枚=プロップ31機能→ロダーリ『ファンタジーの文法』→三藤が日本の子ども向けに選抜・イラスト付与した翻案）：使い方=**①分析**（既存作品に赤で番号を振る）**②発表 ③創作への転用**（どのカードを使うか選ぶ）。まとめの転移の指さし「好きな映画も分析するとあてはまる」。
4. **教え子の実測2サンプル**（非掲載・構造のみ）：**忠実置換型**（メロンひめ=かぼちゃひめ型の完全な写し・結末定型まで）と**破り型**（フレア太郎=冒頭の「遅れて流れてきた桃」を末尾で回収する円環・かっぱ伝承との混成——**18カードに無い伏線回収を自力発明**）——「型どおり」と「型破り」の両方の歩き方が実在した。
5. **権利の要**：土台の桃太郎は**楠山正雄版（1950年没=PD）が青空文庫にある**——昔話の本文を全文掲載できる系列。三藤本は保護中（書誌のみ・かぼちゃひめは題名言及のみ・18カードは写さない）。岩井md末尾の修正版桃太郎は「三藤(2010)を修正」なので**サイトには使わず、楠山底本の再話に組み直す**（岩井のオノマトペ方針〔ぺんたらこっこっこ等の自作オノマトペ〕は移植できる）。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：

> **よくできた物語の「入れ物」（構成）を借りて、中身をぜんぶ入れかえると、新しいお話が立つ。そして入れかえてみたとき、借りた入れ物の形——昔話の骨——が、はじめて手の中に見えてくる。作ることが、いちばん深い分析になる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> 人も、場所も、道具も、ぜんぶ入れかえたのに——どうして、ちゃんとおもしろいお話になってしまう？　ももたろうから、なにを借りている？

（「構成」「骨」の名指しは Step5 の発見なので問いに書かない＝G1）

## 5オペレータ運用

| Op | 実装 |
|---|---|
| 同 | 同じ入れ物で中身を替える（書き換えの本体・6W1Hの置換）。本歌取＝桃太郎の書き換え |
| 逆 | **書き換え→対応の逆引き**：この書き換えで「きびだんご」にあたるものはどれ？／**変わっていないもの**はどれ？（入れ物の発見の入口） |
| ＋α | 制約追加＝**骨を一本足す**（たくらみ・正体がばれる等、元の話に無い機能を一場面だけ足す——教え子の破り型の手つき） |
| 質的変化 | **並べて骨が浮かぶ**＝桃太郎と書き換え例を並べて読むと、共通の形（三回のくりかえし・出発・帰り…）が見えてくる（系列の核＝**比較が構造を見せる**・推理式のメタ適用） |
| 複合 | 差し替え表づくり＋骨を一本足す＋自分の書き換え、で制作 |

## 「昔話の骨の図鑑」（裁定4確定＝**プロップ31機能を全部提示**）

三藤18枚は写さず、**プロップの31機能（理論=アイデア）を子どもの語に自前で言い換えた「骨の図鑑」**を original 教材（mentorText・資料カード）として作る。番号と機能名は訳書によって揺れるため、図鑑には「本によって名前が少しちがう」旨を注記。Step6で図鑑を渡し「**桃太郎に入っていない骨はどれ？**」を問う（分析）→ L3で「書き換え見本には、桃太郎に無い骨が四本足されている」ことを明かし再読を促す（**Step2から読んでいた見本の中の伏線回収**）→ Step9で自分も無い骨を足す（創作転用）——三藤単元25の「分析→創作」の橋を、発見の順序で組み直す。出典＝プロップ『昔話の形態学』（北岡誠司・福田美智代訳・水声社・1987）→ロダーリ『ファンタジーの文法』22章→三藤(2010)の系譜をクレジット。

## 縦の鎖

お話①「もし」（うそ一つ＋筋）→②二項式（タネの作り方）→**③書き換え（入れ物の借り方）**——物語ユニットの三本目で「筋・タネ・入れ物」が揃う。②ロダーリつながり（プロップのカードはロダーリ22章＝**ロダーリ目次の鉱脈の一つがここで実現**）。⑦6つのへや・⑧好きリスト（器を借りる詩）→物語の器を借りる。お話①の「同×3→質的変化」（ファージョンの目録反復）→桃太郎の三回反復＝**同じ骨**。俳句の本歌取→書き換えは散文の本歌取。**数学の推理式（文型×材料の入れ替え）との橋を作家の風景で明言できる唯一の系列**——「算数の文章題で、同じ解き方の問題の数字をかえるのと同じ」。
