## 0. 確定事項（D1〜D6）

### D1. 章の位置——**式と証明は 数Ⅱ の第1章**（C10）

写真（実物 p.8／p.34）で確定：**第1章＝式と証明（p.8〜33）／第2章＝複素数と方程式（p.34〜）**。
これまで memory の章立てメモは数Ⅱ・B の第1章を「複素数と方程式」としていたが、これは誤り。
カタログの 数Ⅱ・B グループの並びは **式と証明 → 複素数と方程式 → 図形と方程式 → 三角関数 → 指数対数 → 微分積分 → 数列 → ベクトル** に直す。

### D2. 入力系ゲート（C1）——**拡張は不要**

この単元の「答え」の生の型は、展開式・因数分解の形・商と余りの整式・分数式・証明の文章と、**ほぼ全部が非数値**。
それでも入力系の拡張なしで核を採点できる。C1 追補（集合と論理の 5 型）・追補 3（証明の 3 住所）・追補 4（判定を値へ）に続く実運用 3 例目として、この単元の折り方を型にする：

| 生の答え | 折り方 | 効く理由 |
|---|---|---|
| 展開した多項式 | **指定した項の係数**（1 step 1 係数） | 展開の核は「どの積がどの項に集まるか」。係数はその集まり方そのもの |
| 因数分解の結果 | **因数の中の指定係数**／2 段階なら段ごとに 1 つ | 「どの公式の形に見立てたか」が係数に出る |
| 二項展開の特定項 | **その項の係数**（そのまま数値） | 二項定理は最初から「係数を答える」道具。折る必要すらない |
| 商と余り（整式） | **商の指定係数／余りの指定係数**を別 step に分ける | 順序対を 1 問で答えさせない（C1 追補 4）。1 step 1 関節＝証明型の折り方（C1 追補） |
| 恒等式の未定係数 | **1 step 1 文字**（$a$ と $b$ を同じ step で答えさせない） | 同上。`solutionSet` は順不同なので $(a,b)$ には原理的に使えない |
| 分数式の計算結果 | **約分後の分母／分子の指定係数**・**部分分数の係数** | 「元の式にそのまま代入すれば当たる」問いを作らない（＝約分せずに答えられてしまう抜け道を塞ぐ） |
| 等式・不等式の証明 | **鎖の関節の数値**（変形の途中の係数・差が 0 になること・平方の中身） | 証明の 3 住所（定理の証明→derivation／骨格→関節の数値／作文→エンジン外 F6） |
| 「常に成り立つ／成り立たない」 | **反例となる整数のうち最小**（真なら反例 0 個） | 反例の一意檻（C1 追補 型②）。一意性は全数走査で機械確認する |
| 相加相乗の最小値 | **最小値そのもの**（無理数なら `[sqrt]`＋`answerDisplay`）と**等号成立の値**を別 step に | 最小値と等号成立は別の問い。分けると「等号を確かめる」習慣が入る |

**C1 追補 2 の適用（値の設計まで見る）**：判定は `TOL=1e-6` の厳密一致。
分数式・相加相乗では割り切れない小数が出やすいので、**割り切れる値・平方数・ちょうど有理数になる組**を選ぶ。
無理数を答えさせるのは「$\sqrt{\ }$ のまま `answerDisplay`＋`inputAffordances: ["sqrt"]`」の 1 通りだけ。丸めた小数は作らない。

### D4. 証明の扱い——図形の性質で確立した **3 住所方式**を踏襲

3. **証明の作文** → **エンジン外**（F6）。完了画面の「じぶんの問題」欄と、紙の練習に委ねる

### D5. 単元のハブ胚細胞

> **数Ⅰまで、式は「値を求めるための手続き」だった。ここで式は「すべての値について同時に成り立つ主張」になる。
> 無限個の代入は確かめられない——だから、係数をくらべる・差をつくって形を見る、という有限の手つきが、その無限を引き受ける。**

- 数Ⅰ「数と式」のハブ＝**帰着**（扱えない形を扱える形に書き換える）の、**主張版**。
  帰着が「解くため」だったのに対し、ここでは「**正しさを保証するため**」に書き換える
- 二本柱：**係数をくらべる**（有限個の係数が無限個の代入を代表する＝系列1〜5）と
  **差をつくる**（大小・一致を引き算の符号に翻訳する＝系列6〜8）
- 展開公式も二項定理も除法の基本式も相加相乗も、すべて「**どんな値でも成り立つと保証された恒等式・不等式の在庫**」。
  在庫は覚えるものではなく、**生やす手つき**を持っていれば忘れても建て直せる（Q7）

### D6. 縦の鎖のどこに刺さるか（VISION.md 用の 1 行）

- **下から**：数Ⅰ [展開][因数分解][平方完成][判別式]／数A [組合せ]（二項係数の正体）・[商と余り]（$A=BQ+R$）／数Ⅰ・A [反例][対偶][背理法]（証明の型）
- **上へ**：数Ⅱ [剰余の定理][因数定理]（除法の基本式の 1 点評価）→ 高次方程式／数B 数列の和（望遠鏡和）／数Ⅲ 極限・有理関数の積分（部分分数）／大学 多項式環の除法・コーシー-シュワルツ・AM-GM の一般形

## 系列3：整式の割り算と除法の基本式

- **id 案**：`algebra2_poly_division_01`
- **中心の問い（胚細胞）**：
  「整数の割り算は『余りが割る数より**小さく**なるまで取り出す』ことだった。**式にも「小さい」はある？**——何が小さくなれば、割り算は終わったと言える？」
  - 胚細胞的概念：**割り算とは、割り切れない分を「もう取り出せない残り」まで押し下げる操作**。
