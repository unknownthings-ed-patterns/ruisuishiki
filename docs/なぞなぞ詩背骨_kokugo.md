## 素材読解——なぞなぞ詩の仕掛け

1. **型**：「これは／◯◯に見える／◯◯みたい／◯◯のようだ／◯◯でもある……（こたえ　△△）」——比喩を重ね、**本体の名前を言わずに伏せる**。読み手は比喩から本体を推理する。
2. **これは推理式そのもの**：「答のみで自得」の詩版——読者が比喩の列から答えを推理する。読む＝解く、書く＝出題する、の読み書き交換が型に内蔵されている。俳句③「切れ」・視覚詩②「さいごの一行」に続く「**言わない意味**」の系譜。
3. **比喩の連打が輪郭を描く**：一つの比喩では決まらない（月？ボート？）。重なると交点に本体が浮かぶ（スプーン）。数学の「条件で絞る」と同型。
4. **さいごの比喩が跳ぶ**：教え子の「本」の詩——おぼん→ステージ→ちょうちょ→窓→布団→まな板、と**形の比喩**を重ねて、結びで「**新しい世界の玄関**」へ——形を超えて**意味の比喩**に跳ぶ。ここでなぞなぞが詩になる。「ハサミ」も同じ（りぼん→…→カニのパーティー→ちいさなハート→ジェットコースター＝動きへ跳ぶ）。スプーンの「銀のしずく」も材質・光への着地。
5. **言い方の散らし**：見える／みたい／のようだ／でもある——同じ助動詞の繰り返しを避けて言い方が回る（子どもの4本すべてで確認）。

## 胚細胞と中心の問い（ドラフト・裁定待ち）

**胚細胞**：共通胚細胞「小さな装置が大きな意味の体系を呼び出す」の**比喩の相**＝

> **にたものの名前をならべると、本体の名前を言わなくても、本体が浮かび上がる——そして、さいごの比喩が形を超えて跳ぶと、なぞなぞが詩になる。**

**中心の問い（drivingQuestion・ドラフト文面）**：

> 名前を一度も言っていないのに、どうしてみんな当てられる？——「◯◯に見える」をいくつもならべると、なにがおきる？

## 5オペレータのなぞなぞ詩運用

| Op | 実装 |
|---|---|
| 同 | 同じ型（これは／比喩の列／こたえ）で材料替え。本歌取＝「スプーン」の型を借りる |
| 逆 | **解く⇄作るの交換**：詩→答えを当てる（読み・推理）と、答え→比喩を出す（書き・見立て）の双方向 |
| ＋α | 制約追加：比喩を5つ以上・言い方を散らす（見える／みたい／のようだ／でもある）・形だけでなく動き/さわりごこちの比喩を入れる |
| 質的変化 | **さいごの比喩が跳ぶ発見**＝結び違い2版（形の比喩で終わる版／最後に意味へ跳ぶ版）の読み比べ（系列の核） |
| 複合 | 比喩5つ＋言い方散らし＋さいごは跳ぶ＋答えを伏せる、で制作 |

## 縦の鎖

俳句③「切れ」（言わない意味）→ 視覚詩②「さいごの一行」→ **本系列「答えを言わない・さいごの比喩が跳ぶ」**。5秒の詩①「物の名前で言う」→ 比喩も物の名前で（つながる道具）。お話①「比喩は物で言う」（ファージョン）とも呼応。**数学との橋**＝「条件をならべて絞る」（比喩の連打で本体が決まる＝集合の交わり）——作家の風景で一言ふれる候補。
