## 0. 冒頭の確定事項（D1〜D7・**2026-08-01 裁定確定＝3点すべて「推奨どおり」**：8系列〔事後の確率は独立・薄ければ系6へ畳むフォールバック付き〕・全8系列実装〔モードA=系1 Fable お手本→系2以降 Opus 委譲＋Fable 検収・機械確認 Sonnet〕・場合の数と並行進行〔commit 直前 rebase・共有ファイルは自ブロック末尾追記・選択的ステージングで相手の未コミット変更を巻き込まない〕）

**D1. 章の範囲と節順は本の実際の並びに従う**（写真で確認・C10）。第5章は **p.205〜p.245** で完結（p.204 まで第4章「場合の数」、p.246 から第6章「集合と論理」）。

> 起こりやすさの度合い（確率メーター・統計的確率）→ 確率の計算（数学的確率・同様に確からしい・**事象を均等な粒にたたき割る**・根元事象・すべて区別する）→ 場合の数の公式の活用（数える基準がぶれないように）→ 確率の「足し算」と「引き算」（排反なら和・余事象）→ 応用問題1 → 確率の「かけ算」（独立な試行・**面積図**）→ 反復試行の公式（1本の道×道の数）→ 条件つき確率（乗法定理・くじ引きの公平性・独立の判定）→ 事後の確率（逆向きの条件つき確率）→ 期待値（重み付き平均・判断基準）

**著者の意図（背骨に反映）**：

- **定義の核は「事象を均等な大きさの粒にたたき割る」**（鉱石→鉱物の含有率メタファ）。粒（根元事象）が同様に確からしくなるまで割るから「個数の比」が確率になる。コイン2枚の 1/3 誤りも、サイコロの和の 1/11 誤りも、すべてこの一点から砕ける
- **「登場する人やモノはすべて区別する」は原則、本質は「分母と分子を同じ基準で数える」**——区別しない基準でも一貫していれば正しい（黒白の別解）。この二段構えをそのまま系2 の骨格にする
- **面積図が章の後半を貫く視覚言語**：独立のかけ算（縦×横）→ 条件つき（全体の縮小）→ 事後（逆読み）→ 独立の判定（縮めても割合が変わらない）まで、同じ長方形の絵で通す。系4〜7 の図をこの一貫性で設計する
- **反復試行の公式は「①1本の道の確率 ②道の数」の分解から生やす**（丸暗記させない）——Q7「忘れても導ける」と完全に同型
- 和の法則は場合の数の写し絵。**かけ算だけが場合の数に無かった新しい演算**（数えずに確率どうしを組み合わせる世界の入口）

**この章に無いもの**：順列・組合せの公式そのもの（第4章。本章は使う側）・統計的確率の本格運用（データの分析・数B）・確率分布（数B）。二項定理（数Ⅱ）。

**D2. 入力系の拡張は不要**（C1 ゲート通過）。この章の答えはすべて**分数（確率）または整数（期待値の点数/金額・逆算の個数/回数）**で、現行入力系（分数・整数）で採点できる。√・π・複数解（solutionSet）・記号入力は不要。

| 内容 | 素の答え | 折り方 | affordances |
|---|---|---|---|
| 事象の確率 | 分数（0〜1） | そのまま分数入力 | プレーン（分数可・unit なし） |
| 期待値 | 分数または整数 | そのまま。金額・点数の場面では整数になる値を選んでよい | プレーン（unit「円」「点」等） |
| 逆向き（確率から個数・回数・人数を逆算） | 非負整数 | そのまま | プレーン（unit「個」「回」等） |
| 「得か損か」の判断 | 判断 | **期待値と参加費の差**（数値）を答えさせ、判断の言葉は L3/derivation で扱う | プレーン（unit「円」） |
| P_A(B) などの記号 | — | **学習者に入力させない**。問題文・ヒント側にのみ登場し、答えは常に数値 | — |

**約分の扱い**：評価器は数値評価なので未約分（例 4/36）でも正解になる。**これは仕様として許容**（「同じ数の別の顔」）。約分した形は answerDisplay と L3 が見せる。

**禁止**：答えが 0 または 1 になる確率の問いは避ける（採点はできるが推理の質が下がる）。分母が巨大になる値（4桁超）は選ばない。

**この折り方が学びとして効く理由**：確率の答えは分数1つだからこそ、**分母の設計（何を全体にしたか・区別したか）と分子の数え（もれ・重複・基準のぶれ）を誤った瞬間に答えが変わる**。この章の概念の核＝「均等な粒・基準の一貫性・排反・独立・条件」が、そのまま採点対象になる。

**D5. 系列の切り方は 8 系列**（C9・厚み基準。§1 の一覧）。判断の要点：

- **定義（系1）と場合の数の活用（系2）を分ける**。本では連続する節だが、系1 の胚細胞は「均等な粒への分割」、系2 の胚細胞は「分母と分子の基準の一貫性」で別物。系1 は道具が小さい（列挙・表）うちに定義の核を打ち込み、系2 で第4章の公式群を一気に呼び込む（合流の主役）——ここを混ぜると、単元最初の系列が公式頼みになり定義が痩せる
- **和と余事象は 1 系列に統合**（系3）。本でも「足し算と引き算」が一節。排反・全体1・補集合はひとつの絵（面積の分割）の3つの顔
- **応用問題1（サイコロ3個・ジャンケン）は独立系列にしない**。系2〜3 の複合 step の素材構造として吸収
- **かけ算（系4）と反復試行（系5）を分ける**。系4 の胚細胞は「独立＝影響しない→積（面積）」、系5 は「1本の道×道の数」——後者は前者と第4章の組合せの合成で、山場（プレイオフ型の順番制約）も独自。本でも別節
- **条件つき確率（系6）と事後の確率（系7）を分ける**。系6 は時間の順向き（全体の縮小・乗法定理・独立の判定）、系7 は**向きの逆転**（結果から原因を問う・ベイズの芽）。本でも「事後の確率」は独立の節で、「ちょっと変」という認識の段差を著者自身が名指している。**フォールバック（C9）**：歩行後に系7 が薄いと判れば、系6 の step8〜10 へ畳む（事後1問＋帽子型1問＋総合1問に圧縮）
- **期待値は独立系列**（系8）。確率×値の重み付き平均という新しい量で、判断基準（参加費と比べる）という使い道まで持つ。数直線の重み付き平均・小5 の平均との縦の鎖も張れる

**D7. 実装順**：系1 → 系8 の本の節順どおり 1 系列ずつ（実装 → `audit_hints.py` 100% → 全問 Python 検算 → tsc/build → commit/push → デプロイ確認）。開発モード A：系1 を Fable がお手本実装 → 系2 以降は Opus 委譲＋Fable 検収（7条件＋Q1〜Q7 の2段構え）。機械確認（audit・検算・tsc/build・grep 監査）は Sonnet 委譲可。

## 1. ハブ胚細胞と縦の鎖

**ユニットのハブ胚細胞＝「起こりやすさは、『同様に確からしい粒』までたたき割れば場合の数の比という1つの数になる——そして数えきれない世界では、確率どうしを、排反なら足し・独立ならかけ・情報で全体を縮め・全体1から引くことで組み立てられる。期待値はその総仕上げ＝確率を重みにした、まだ起きていない未来の平均」**。

第4章ハブ「数えにくいものを数えやすい形に帰着させる」の続編：**測りにくい『起こりやすさ』を、数えられる粒に帰着させる**（相A）。そして粒を数えきれなくなったとき、**確率という数そのものの演算**（足す・かける・縮める・引く）に帰着させる（相B）。

- **相A：粒を数える**（均等な粒への分割・場合の数の公式・基準の一貫性）＝系1〜3
- **相B：確率を組み立てる**（独立の積・反復試行・条件つき・事後）＝系4〜7
- **相C：未来を1つの数に**（期待値＝確率を重みとする平均・判断基準）＝系8

```
小5 割合 ratio_basic_01 ✅ ／ 平均 e5_mean_01 ✅ ／ 数直線の重み付き平均 adv_number_line_01 ✅
中学 middle_combination_01（組・確率の基礎）✅
数Ⅰ・A 場合の数 系1〜10（seriesCounting.ts・実装進行中）
  → 系1 確率の定義（均等な粒にたたき割る）
  → 系2 場合の数との合流（分母と分子は同じ基準）   (合流: 順列・組合せ・同じものを含む順列)
  → 系3 足し算と引き算（排反と余事象・全体は1）     (合流: 引き算で数える)
  → 系4 かけ算（独立な試行・面積で重ねる)
  → 系5 反復試行（1本の道×道の数）                 (合流: 組合せ)
  → 系6 条件つき確率（情報が全体を縮める）
  → 系7 事後の確率（結果から原因を問う）
  → 系8 期待値（確率を重みにした平均）             (合流: 平均・重み付き平均)
  → 前方: 数B 統計的な推測（未実装）／数Ⅱ 二項定理（未実装）／データの分析（統計的確率）
```

**VISION の鎖への1行**：離散の背骨の第2段（場合の数の真上）。ここで「不確実さを数で扱う」言語が初めて立ち、数B の統計的推測・大学の確率論/統計学・機械学習（事後確率）までこの上に載る。

## 2. 系1：確率の定義（均等な粒にたたき割る）

- **id 案**: `algebra1_prob_def_01`
