## 0. 冒頭の確定事項（D1〜D7・**2026-08-01 裁定確定＝4点すべて「推奨どおり」**：10系列・カタログ移動・全系列実装〔系1=Fable お手本→系2以降 Opus 委譲＋Fable 検収〕・旧コンテンツ処遇）

**D1. 章の範囲と節順は本の実際の並びに従う**（写真で確認・C10）。第4章は **p.153〜p.204** で完結（p.152 まで第3章「三角比」、p.205 から第5章「確率」）。

> ものを数える素朴なアイデア（分ける=足す・まとまり=かける・置き換える・残った方=引く。標語「**もれなく，重複なく**」）→ 数え上げの基本（規則を決めて書き並べる・樹形図）→ 積の法則 → 和の法則（＋足すかかけるかの使い分け）→ 包除原理・背番号 → 残った方に注目する → 応用問題1 → **「割り算」の考え方（重複度）** → 順列の公式（nPr・n!）→ 重複順列（n^r）→ 組合せの公式（nCr・Step1〜3 の型）→ 円順列（割るか固定するか）・数珠順列 → 同じものを含む順列 → 1対1の対応（最短経路）→ 応用問題2〜5（多角形・部屋割り・グループ分け・重複組合せ）

**著者の意図（背骨に反映）**：公式群（P・C・階乗・n^r・(n−1)!・n!/p!q!…）を最初から出さず、**四則の工夫（足す・かける・引く・割る）＋置き換え（1対1対応）を先に半章かけて渡し、公式はぜんぶ「よく使う工夫の詰め合わせ」として後から生やす**。とくに「割り算＝重複という敵を味方にする」（重複度）と「**Step1 いったん区別して数える → Step2 重複度を調べる → Step3 割る**」の型が後半の全公式（組合せ・円順列・同じものを含む順列・グループ分け）を貫く背骨。この構成をそのまま系列の骨格にする。

**この章に無いもの**：確率（第5章）・二項定理（数Ⅱ）・集合の記号論（∩∪ の形式的運用は最小限）。重複組合せは応用問題としてのみ登場（独立節ではない）→ 系10 の山場に置き、独立系列にはしない。

**D2. 入力系の拡張は不要**（C1 ゲート通過）。この章の答えはすべて**非負整数**（「何通り」「何個」「何本」）で、現行入力系（プレーン数値）で採点できる。√・π・分数・複数解も不要。

| 内容 | 素の答え | 折り方 | affordances |
|---|---|---|---|
| 並べ方・選び方・経路などの総数 | 非負整数 | そのまま | プレーン（unit「通り」） |
| 個数・本数（倍数・対角線など） | 非負整数 | そのまま | プレーン（unit「個」「本」） |
| 逆向き（総数から人数・回数を逆算） | 非負整数 | そのまま | プレーン（unit「人」「個」等） |
| nPr・nCr・n! などの記号 | — | **学習者に入力させない**。問題文・ヒント側にのみ登場し、答えは常に数値 | — |
| 場合分けの各ケース数 | 組 | **1 ケースずつ別 step**、または最終総数のみ問う | プレーン |

**禁止**：記号（P・C・!）を答えさせない。順序が意味を持つ組を `solutionSet` で答えさせない（従来どおり）。5 桁程度の大きい答えは可（評価器は桁区切り入力も許容済み）が、**檻のない巨大計算はさせない**——大きい値は「式の組み立てが正しければ電卓的計算は L3 が見せる」設計にせず、そもそも計算が手に負える値を選ぶ。

**この折り方が学びとして効く理由**：答えが常に 1 つの整数だからこそ、**式の組み立て（かけるか足すか・何で割るか）を誤った瞬間に答えが変わる**。使い分け・重複度・同一視のルールという概念の核が、そのまま採点対象になる。

- **重複組合せは 1対1の対応（系10）の山場に吸収**（応用問題扱い・「仕切り線への置き換え」は系10 の胚細胞の最良の実例）

## 1. ハブ胚細胞と縦の鎖

**ユニットのハブ胚細胞＝「数えるとは、数えにくいものを『数えやすい形』に帰着させる工夫である——分けて足す・まとまりでかける・残りを引く・重複度で割る・1対1対応で置き換える。公式はすべてこの工夫の詰め合わせであり、忘れても樹形図と重複度から生やせる」**。

数Ⅰハブ「扱えない形を扱える形に書き換える（帰着）」の**離散版**。「もれなく、重複なく」は帰着が保つべき不変量（何も失わず・何も二重にしない）である。

- **相A：規則と四則の工夫**（規則を決めて数える → かける/足す → 引く → 割る）＝系1〜4
- **相B：工夫の詰め合わせ＝公式**（順列・重複順列・組合せ・円順列・同じものを含む順列）＝系5〜9
- **相C：置き換えの自由**（1対1対応・最短経路・重複組合せ）＝系10

```
小学校 かけ算の表・整理と分類 ✅
中学 middle_combination_01（組 C(n,2)・確率の基礎）✅
数Ⅰ 数と式（ハブ「帰着」）✅
  → 系1 数え上げの基本（規則が「もれなく重複なく」を作る）
  → 系2 積の法則と和の法則（かけるか、足すか）   (横: 整数の性質・約数の個数)
  → 系3 引き算で数える（残った方・包除原理）
  → 系4 割り算で数える（重複度）                 ←単元後半の型の土台
  → 系5 順列（減りながらかける）                 (旧 algebra_perm_01 吸収)
  → 系6 重複順列（減らない枝）
  → 系7 組合せ（並べるを r! で割る）             (横: 中学 組合せ)
  → 系8 円順列（同一視が重複度を決める）
  → 系9 同じものを含む順列（区別をつけて、割って消す）
  → 系10 1対1の対応（数える対象を選び直す）
  → 第5章 確率（未実装・前方）／数B 統計的な推測／数Ⅱ 二項定理
```

**VISION の鎖への1行**：このユニットは「数→式」「静→動」とは別の第3の柱＝**離散の背骨の最下段**。確率（数A）・統計（数B）・二項定理・数列（数Ⅱ）から大学の組合せ論・確率論まで、この上に載る。

## 3. 系2：積の法則と和の法則（かけるか、足すか）

## 4. 系3：引き算で数える（残った方に注目・包除原理）

- **id 案**: `algebra1_count_subtract_01`
- **中心の問い（胚細胞）**：「『少なくとも 1 つ』や『AまたはB』を、なぜ**まともに数えないほうが**速くて確実なのか？——全体の数が分かっているなら、欲しい数は『残りを引く』か『足しすぎを引いて直す』かで手に入るとしたら、数える相手は選び直せるか？」
  - 胚細胞的概念：**数えにくいものは数えやすい相手（補集合・重なり）に取り替えて引く——数える対象を選ぶ自由**。転移先：確率の余事象・包除原理の一般形
- **既知→未知の橋**：系2（全体を積で数える）＋生活の既知（残った整理券で配った数を知る）。step1 Socratic 案：「番号の並んだ列の長さを数えるとき、端の番号どうしを引き算するだけでは 1 つずれる。並んだものの数と『すき間』の数、どちらが引き算の答え？」
